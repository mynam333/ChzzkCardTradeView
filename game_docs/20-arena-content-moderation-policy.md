# 치카포 아레나 콘텐츠 모더레이션 정책

## 1. 목적

이 문서는 치카포 아레나에서 카드 이미지, 카드명, 사용자 닉네임, 덱 이름, 링크 공유 리플레이, 시즌 통계가 부적절하게 사용될 때의 신고, 제한, 블라인드 처리 기준을 정의한다.

## 2. 모더레이션 대상

- 스트리머 카드 이미지
- 스트리머 카드 표시명
- 유저 닉네임
- 덱 이름
- 리플레이 제목 또는 공유 문구
- 공개 리플레이 썸네일
- 시즌 랭킹 표시명
- 관리자 선정 경기 소개 문구

## 3. 금지 콘텐츠

금지:

- 혐오/차별 표현
- 성적이거나 선정적인 이미지
- 폭력적 위협
- 개인정보 노출
- 사칭
- 불법 행위 홍보
- 권리자가 사용을 원하지 않는 이미지
- 스트리머를 조롱하거나 악의적으로 편집한 카드 표시
- 운영자 또는 공식 공지로 오인될 수 있는 이름

## 4. 신고 처리

신고 항목:

```text
target_type
target_id
reporter_user_id
reason
description
created_at
status
handled_by
handled_at
```

처리 상태:

```text
OPEN
REVIEWING
ACTIONED
REJECTED
ESCALATED
```

우선순위:

1. 개인정보 노출
2. 권리자/스트리머 직접 요청
3. 혐오/성적 이미지
4. 사칭
5. 기타 부적절 표현

## 5. 임시 조치

운영자는 검토 중 아래 조치를 할 수 있다.

- 카드 이미지 임시 대체
- 공개 리플레이 비공개
- 덱 이름 기본값 변경
- 닉네임 제한 표시
- 카드 도감 숨김
- 시즌 통계에서 이미지 제거

임시 조치는 전투 결과, MMR, 랭킹을 직접 변경하지 않는다.

## 6. 공개 리플레이 기준

MVP에서는 전체 목록에 노출되는 공개 리플레이를 제공하지 않는다. 리플레이는 기본 비공개이며, 참가자가 생성한 만료 토큰 링크를 가진 사람만 제한적으로 조회할 수 있다.

정식 시즌 이후 공개 목록형 리플레이를 제공하려면 아래 조건을 충족해야 한다.

- 참가자 공개 여부 정책 확정
- 스트리머 비활성화 카드 자동 마스킹
- 신고 버튼 제공
- 리플레이 블라인드 처리 가능
- 썸네일 대체 가능
- 내부 시드와 검증 해시 비노출

## 7. 카드 이미지 대체 기준

대체 표시가 필요한 경우:

- 스트리머 비활성화
- 권리 요청
- 부적절 이미지 신고 승인
- 이미지 로드 실패
- 관리자 임시 제한

대체 방식:

- 기본 실루엣 이미지
- 역할군 아이콘
- “비활성화된 카드” 표시명
- 전투 로그에서는 익명 카드 ID 유지

## 8. 사용자 고지

조치 대상 사용자 또는 스트리머에게 가능한 범위에서 안내한다.

고지 내용:

- 조치 대상
- 조치 사유
- 조치 범위
- 이의 신청 경로
- 재검토 예상 기간

단, 어뷰징 조사나 보안상 필요한 경우 세부 근거는 제한할 수 있다.

## 9. 관리자 감사 로그

모든 모더레이션 조치는 감사 로그를 남긴다.

필수 필드:

```text
admin_user_id
action
target_type
target_id
before
after
reason
created_at
```

## 10. 출시 전 필수 기능

MVP 필수:

- 스트리머 비활성화에 따른 이미지 대체
- 관리자 카드 숨김/표시 제한
- 리플레이 비공개 기본값
- 관리자 감사 로그

정식 시즌 전 필수:

- 신고 접수 기능
- 링크 공유 리플레이 블라인드/토큰 폐기 기능
- 대체 썸네일
- 닉네임/덱 이름 제한 표시
