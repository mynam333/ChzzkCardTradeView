# 치카포 아레나 밸런스 검증 및 운영 정책

## 1. 목적

이 문서는 치카포 아레나의 카드, 클래스, 스킬, 패시브, 시너지 태그, 덱 조합, 5판 3선승 세트 매치의 밸런스를 검증하고 운영하는 기준을 정의한다.

치카포 아레나는 약 3,000장의 스트리머 카드가 존재할 수 있으므로 수작업 감각만으로 밸런스를 맞출 수 없다. 모든 핵심 변경은 자동 시뮬레이션, 통계 기준, 운영 정책을 통과해야 한다.

핵심 목표:

- 경쟁 모드의 공정성 유지
- Pay to Win 요소 차단
- 특정 클래스/태그/스킬 독주 방지
- 스트리머 직접 설정 카드의 밸런스 검증
- 서버 부하를 고려한 저비용 밸런스 테스트
- 시즌제 운영에 맞는 안정적인 패치 정책 수립

## 2. 절대 원칙

아레나 밸런스는 치카포 본편의 경제/인기 지표와 독립되어야 한다.

전투 밸런스에 사용 금지:

- 카드 시세
- 팔로워 수
- 방송 중 여부
- 방송 시간
- 채팅량
- 치카포 포인트
- 카드 보유 수량
- 마켓 거래가
- 유저 자산

밸런스 검증 대상:

- 역할군
- 클래스
- 스탯 프로필
- 액티브 스킬
- 패시브 스킬
- 시너지 태그
- 라운드별 전술 플랜
- 덱 조합
- 카드 생성 파워 점수
- 5판 3선승 세트 승률

## 3. 밸런스 단위

### 3.1 개별 카드

개별 스트리머 카드의 성능을 본다.

지표:

- 세트 승률
- 라운드 승률
- 픽률
- 밴률. 전략 플랜 도입 이후
- 평균 피해량
- 평균 생존 시간
- 평균 회복/보호막 기여
- MVP 선정률
- 특정 조합 의존도

### 3.2 클래스

클래스는 밸런스 패치의 핵심 단위다.

지표:

- 클래스별 세트 승률
- 클래스별 픽률
- 클래스별 평균 라운드 승률
- 클래스별 평균 매치 길이
- 클래스별 상대 역할군 승률
- 클래스별 태그 조합 승률

### 3.3 스킬

액티브/패시브 스킬은 독립적으로 추적한다.

지표:

- 스킬 보유 카드 평균 승률
- 스킬 발동 횟수
- 스킬 사용 후 승률 변화
- 피해/회복/보호막 기여량
- 상태이상 적용 성공률
- 로그 이벤트 발생량
- 특정 스킬 조합 승률

### 3.4 시너지 태그

태그는 덱 빌딩의 메타를 만든다.

지표:

- 태그 2/4/6단계별 승률
- 태그 단계별 픽률
- 태그 조합별 승률
- 태그 카운터 관계
- 태그가 전투 시간을 늘리는 정도
- 태그가 특정 클래스에 과도하게 의존하는지

### 3.5 전술 플랜

5판 3선승에서는 라운드별 사전 전술 플랜도 밸런스 대상이다.

지표:

- 1라운드 플랜 승률
- 2라운드 플랜 승률
- 3라운드 플랜 승률
- 같은 덱의 플랜 변경 효과
- 특정 플랜이 모든 상대에게 우세한지
- 3:0 승리 비율
- 3:2 승리 비율

## 4. 핵심 허용 범위

### 4.1 카드 승률

랭크 데이터 기준 최소 표본을 넘긴 카드만 판단한다.

최소 표본:

```text
카드별 최소 매치 수: 300
카드별 최소 픽률: 전체 활성 카드 내 0.5%
```

권장 세트 승률:

```text
정상: 47% ~ 53%
주의: 45% ~ 47% 또는 53% ~ 55%
위험: 42% ~ 45% 또는 55% ~ 58%
긴급: 42% 미만 또는 58% 초과
```

낮은 픽률에서 높은 승률이 나오는 카드는 장인형 카드일 수 있으므로 즉시 너프하지 않는다. 높은 픽률과 높은 승률이 동시에 나타날 때 우선 대응한다.

### 4.2 클래스 승률

클래스는 카드보다 표본이 많으므로 더 엄격하게 본다.

```text
정상: 48% ~ 52%
주의: 46% ~ 48% 또는 52% ~ 54%
위험: 44% ~ 46% 또는 54% ~ 56%
긴급: 44% 미만 또는 56% 초과
```

### 4.3 태그 승률

태그는 단계별로 본다.

```text
2단계 정상: 48% ~ 52%
4단계 정상: 49% ~ 53%
6단계 정상: 50% ~ 54%
```

6단계는 덱 빌딩 비용이 높으므로 약간 높은 승률을 허용할 수 있다. 하지만 56%를 넘으면 위험으로 본다.

### 4.4 평균 매치 시간

한 게임 체감 목표는 7~12분이지만, 서버 시뮬레이션과 로그 크기는 제한되어야 한다. 5판 3선승은 라운드 수가 늘어나므로 라운드별 시간, 이벤트 수, 소환수 수, 상태이상 중첩 상한을 더 엄격하게 관리한다.

서버 시뮬레이션 기준:

```text
평균 라운드 시뮬레이션 시간: 35~50초 내부 전투 시간
평균 세트 라운드 수: 3.6~4.4
3:0 비율: 15%~30%
3:1 비율: 30%~45%
3:2 비율: 30%~45%
세트 무승부 비율: 2% 이하
```

실제 서버 계산 시간 목표:

```text
평균 세트 계산 시간: 100ms 이하
상위 95% 세트 계산 시간: 500ms 이하
상위 99% 세트 계산 시간: 1200ms 이하
```

이 값은 구현 언어와 서버 상태에 따라 달라질 수 있으므로 실제 측정 후 조정한다.

## 5. 자동 시뮬레이션

### 5.1 목적

자동 시뮬레이션은 출시 전과 시즌 중 밸런스 변경의 안전성을 검증하기 위한 도구다.

사용 시점:

- 신규 클래스 추가 전
- 신규 스킬 추가 전
- 신규 태그 추가 전
- 카드 능력/사용 가능 상태 재검증 전
- 스트리머 설정 카드 승인 전
- 밸런스 패치 전
- 긴급 너프/버프 전

### 5.2 시뮬레이션 종류

#### Smoke Simulation

빠른 유효성 검사.

```text
목표: 크래시, 무한 루프, 로그 폭증, 제한값 초과 탐지
매치 수: 1,000~5,000
실행 시점: 모든 변경 PR 또는 배치 전
```

#### Balance Simulation

기본 밸런스 검증.

```text
목표: 클래스/스킬/태그 승률 분포 확인
매치 수: 50,000~200,000
실행 시점: 카드 능력/사용 가능 상태 재검증, 패치 전
```

#### Stress Simulation

서버 부하와 최악 조합 검증.

```text
목표: CPU, 메모리, 로그 크기, 이벤트 폭증 확인
매치 수: 10,000
대상: 위험 조합, CC 조합, 회복 조합, 소환 조합
```

#### Regression Simulation

이전 시즌/패치 대비 변화를 확인한다.

```text
목표: 변경 전후 승률 차이 비교
대상: 상위 50개 조합, 문제 조합, 핵심 봇 덱
```

### 5.3 시뮬레이션 덱 구성

자동 시뮬레이션은 무작위 덱만으로는 부족하다.

덱 유형:

- 무작위 합법 덱
- 역할군 균형 덱
- 태그 2단계 중심 덱
- 태그 4단계 중심 덱
- 태그 6단계 중심 덱
- 메타 예상 덱
- 카운터 덱
- 극단 조합 덱
- 봇 연습전 덱

극단 조합:

- 최대 회복
- 최대 보호막
- 최대 CC
- 최대 공속
- 최대 후열 암살
- 최대 광역 DOT
- 최대 에너지 획득
- 최대 소환

### 5.4 5판 3선승 시뮬레이션

모든 밸런스 시뮬레이션은 단판이 아니라 세트 매치를 기준으로 한다.

필수 집계:

```text
set_win_rate
round_win_rate
round_1_win_rate
round_2_win_rate
round_3_win_rate
match_score_2_0_rate
match_score_2_1_rate
draw_round_rate
match_draw_rate
average_round_count
average_match_duration
```

라운드별 전술 플랜이 있는 덱은 플랜을 그대로 적용한다. 플랜이 하나뿐인 덱은 모든 라운드에 같은 배치를 사용한다.

## 6. 스트리머 설정 카드 검증

### 6.1 검증 필요성

스트리머가 자신의 카드 콘셉트를 직접 설정할 수 있더라도, 경쟁 게임에서는 모든 설정이 검증되어야 한다. 설정 권한은 개성 표현 권한이지, 강한 카드를 만들 권한이 아니다.

### 6.2 검증 단계

1. 권한 확인
2. 선택지 유효성 확인
3. 파워 예산 확인
4. 금지 조합 확인
5. 전투 엔진 제한 확인
6. Smoke Simulation
7. 후보군 상대 Balance Simulation
8. 승인 또는 거절

### 6.3 자동 승인 조건

다음 조건을 모두 만족하면 자동 승인 가능하다.

```text
power_score: 95~105
forbidden_combo: 없음
smoke_simulation: 통과
expected_win_rate: 48%~52%
log_size_p95: 제한 이하
cc_uptime: 제한 이하
heal_output: 제한 이하
```

### 6.4 수동 검토 조건

다음 중 하나라도 해당하면 관리자 검토가 필요하다.

- 예상 승률 52% 초과 또는 48% 미만
- CC uptime이 높은 카드
- 회복/보호막 기여량이 높은 카드
- 후열 암살 능력이 높은 카드
- 로그 이벤트가 많은 카드
- fallback이 반복 발생한 카드
- 플레이버 텍스트 신고 가능성

### 6.5 거절 조건

- 금지 조합 포함
- power_score 105 초과 또는 95 미만
- 무한 루프 가능성
- 세트 승률 55% 초과
- 세트 승률 45% 미만. 너무 약한 카드도 거절 가능
- 전투 로그 제한 초과
- 상태이상 연쇄로 상대 행동 불능 시간이 과도함
- 정책 위반 텍스트

## 7. 패치 정책

### 7.1 시즌 중 패치 원칙

시즌 중에는 카드 정체성을 과도하게 바꾸지 않는다.

허용:

- 명백한 버그 수정
- 무한 루프 차단
- 서버 부하 유발 조합 비활성화
- 긴급 너프/버프
- 설명문 오류 수정

가급적 다음 시즌으로 미룰 것:

- 클래스 구조 변경
- 스킬 리워크
- 태그 효과 대규모 변경
- 카드 생성 규칙 변경
- 카드 역할군 변경

### 7.2 긴급 패치 조건

다음 조건 중 하나라도 만족하면 긴급 패치 대상이다.

- 특정 조합 세트 승률 60% 초과
- 특정 클래스 승률 57% 초과
- 특정 카드 픽률 25% 이상 + 승률 55% 이상
- 특정 조합이 매치 평균 시간을 6분 체감 이상으로 늘림
- 전투 로그 제한을 자주 초과
- 서버 CPU/메모리에 실질적인 부하 유발
- 무한 루프 또는 재현 가능한 크래시

### 7.3 긴급 대응 단계

1. 문제 조합 탐지
2. 관리자 공지
3. 임시 금지 또는 효과 하향
4. Smoke Simulation
5. 짧은 Balance Simulation
6. 배포
7. 24시간 모니터링

심각한 경우에는 해당 스킬/태그/카드를 임시 비활성화한다.

### 7.4 패치 주기

권장:

```text
정기 밸런스 패치: 2주 또는 시즌 중간 1회
긴급 핫픽스: 필요 시
시즌 대형 패치: 시즌 종료 후
```

## 8. 버프/너프 방식

### 8.1 숫자 조정 우선

가능하면 리워크보다 숫자 조정을 우선한다.

조정 가능 항목:

- 피해 계수
- 회복 계수
- 보호막 계수
- 지속시간
- 발동 확률
- 에너지 비용
- 쿨다운
- 최대 발동 횟수
- 상태이상 지속시간

### 8.2 구조 변경은 신중하게

구조 변경은 카드 정체성을 바꾸므로 시즌 종료 후 적용한다.

구조 변경 예:

- 타겟팅 룰 변경
- 스킬 종류 변경
- 역할군 변경
- 시너지 태그 변경
- 스탯 프로필 변경

### 8.3 약한 카드 버프

약한 카드도 방치하면 안 된다.

버프 후보:

- 세트 승률 45% 미만
- 픽률 0.3% 미만
- 같은 역할군 내 대체 카드보다 모든 지표가 낮음
- 사용자가 이해하기 어려운 효과

버프 방식:

- 스킬 계수 소폭 증가
- 에너지 비용 감소
- 발동 조건 완화
- 스탯 프로필 cost 보정
- 태그 시너지와의 연결 강화

## 9. 메타 다양성 기준

상용 게임으로 유지하려면 “정답 덱 하나”가 생기면 안 된다.

전체 활성 카드 기준 목표:

```text
상위 1개 덱 픽률: 12% 이하
상위 3개 덱 합산 픽률: 28% 이하
상위 10개 덱 합산 픽률: 55% 이하
역할군별 픽률: 각 10% 이상
태그별 4단계 이상 완성률: 핵심 태그별 3% 이상
```

위 기준은 시즌 초반에는 흔들릴 수 있다. 시즌 3~5일차 이후부터 판단한다.

## 10. 부하 관련 밸런스 기준

밸런스는 재미뿐 아니라 서버 비용도 포함한다.

위험한 효과:

- 짧은 tick마다 이벤트를 발생시키는 DOT
- 다수 대상 반복 연쇄
- 소환수 대량 생성
- 패시브 반복 발동
- 회복/보호막으로 전투를 끝내지 못하게 만드는 조합

제한 기준:

```text
MAX_EVENTS_PER_ROUND = 800
MAX_EVENTS_PER_MATCH = 2400
MAX_MATCH_LOG_BYTES = 320KB
MAX_PASSIVE_TRIGGERS_PER_ROUND = 300
MAX_SUMMONS_PER_PLAYER = 2
```

어떤 조합이 재미있어도 이 제한을 자주 초과하면 밸런스 실패로 본다.

## 16. 반드시 지켜야 할 결정 사항

1. 밸런스 판단은 단판이 아니라 5판 3선승 세트 승률을 기준으로 한다.
2. 라운드 승률, 3:0/3:1/3:2 비율, 세트 무승부 비율을 함께 본다.
3. 스트리머 직접 설정 카드도 자동 생성 카드와 동일한 검증을 통과해야 한다.
4. 치카포 시세, 팔로워, 방송 중 여부, 채팅량, 포인트, 카드 보유량은 밸런스 지표나 전투 보정에 사용하지 않는다.
5. 서버 부하를 유발하는 조합은 재미와 별개로 밸런스 실패로 본다.
6. 시즌 중에는 리워크보다 숫자 조정을 우선한다.
7. 무한 루프, 로그 폭증, 상주 처리 유발 조합은 즉시 차단한다.
8. 모든 밸런스 패치는 시뮬레이션 결과와 함께 기록한다.

## 16. 확장 전략 요소 밸런스 기준

5판 3선승 확장 이후에는 카드 자체보다 조합과 전략 옵션의 영향이 커진다.

추가 밸런스 대상:

- 라운드별 직접 전술 선택
- 예비 카드 투입 패턴
- 전술 칩
- 전장 규칙
- 8인 컵 전용 규칙
- 관전 공개용 하이라이트 선정 기준

금지:

- 밴픽 도입
- 시즌 로테이션 카드 풀로 메타를 인위적으로 제한
- 표본이 적은 통계를 근거로 즉시 너프
- 관리자 화면 요청마다 실시간 전체 통계 집계

전술 칩 위험 기준:

- 픽률 30% 이상 + 세트 승률 54% 이상이면 검토
- 픽률 45% 이상이면 승률과 무관하게 다양성 위험
- 특정 클래스와 조합 시 승률 58% 이상이면 조합 제한 또는 칩 수치 조정

전장 규칙 위험 기준:

- 특정 역할군 승률을 4%p 이상 밀어주면 조정
- 평균 매치 길이를 15% 이상 증가시키면 조정
- 이벤트 로그 수를 20% 이상 증가시키면 저부하 기준 실패

8인 컵 위험 기준:

- 특정 조합의 1~2위 비율이 기대값 대비 2배 이상이면 검토
- 컵 상세 로그 저장량이 목표치를 넘으면 하이라이트 저장 범위를 축소
- 컵 시뮬레이션 p95가 목표를 넘으면 컵 kill switch 또는 동시 처리 수 0 적용

통계 운영:

- 관리자 페이지는 `arena_balance_stat_snapshots`를 조회한다.
- 통계 스냅샷은 30~60분 또는 수동 배치로 생성한다.
- 표본 수 기준 미달 항목은 `표본 부족`으로 표시한다.
