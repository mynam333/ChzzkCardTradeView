# 치카포 프론티어 게임 기획 문서

`치카포 프론티어`는 치카포의 기존 카드 수집, 스트리머 커스텀 이미지, 시세, 별 등급, 교환/마켓 경제를 기반으로 확장하는 신규 대형 방치형 RPG 서비스다.

이 폴더는 게임 전체 기획과 세부 시스템을 분리해 관리한다. 각 문서는 독립적으로 읽을 수 있어야 하며, 구현 단계에서는 이 문서들을 기준으로 DB/API/UI/밸런스 설계를 파생한다.

## 핵심 의사결정

- 신규 서비스는 아케이드 확장이 아니라 별도 메뉴와 성장/시즌 구조를 가진 `치카포 프론티어`로 설계한다.
- 1차 장르는 방치형 원정 RPG다.
- 스트리머는 자신의 카드 빌드를 직접 정한다.
  - 클래스 1개
  - 능력치 20포인트 배분
  - 패시브 스킬 2개
- 유저는 클래스가 부여된 스트리머 카드를 수집해 파티를 편성한다.
- 방치형이지만 서버는 유저별 실시간 tick을 돌리지 않는다.
- 원정/전투 시작 시 카드 빌드를 스냅샷으로 고정하고, 결과 수령 시 한 번만 정산한다.
- 클래스/스킬 데이터는 이후 보스 레이드, 비동기 오토리그, 지역 점령전, 로그라이트 던전에서도 재사용한다.

## 1차 출시 권장 범위

- 클래스: 24종
- 패시브: 48종
- 역할군: 8종
- 파티 크기: 4장
- 원정 지역: 5개
- 원정 시간: 15분, 1시간, 4시간, 8시간
- 주간 보스: 1종 베타
- 오토리그: UI/데이터 구조만 준비하고 정식 경쟁은 2차 이후
