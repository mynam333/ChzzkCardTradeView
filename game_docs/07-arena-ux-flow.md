# 치카포 아레나 UX 및 화면 흐름 기획서

## 1. 목적

이 문서는 치카포 아레나의 사용자 경험, 화면 구조, 주요 플로우를 정의한다.

치카포 아레나는 카드 기반 5판 3선승 자동 전투 게임이다. 유저는 전투 전에 보유 카드로 덱만 준비하고, 빠른대전 또는 AI 봇 연습전을 시작한다. 서버는 매치 생성 시 덱 스냅샷과 전장을 고정한 뒤, 각 라운드 시작 전 유저가 고른 전술로 해당 라운드만 확정한다. 클라이언트는 확정된 라운드를 이어 재생해 전략을 바꾸며 싸우는 전투 경험을 제공한다.

UX 목표:

- 처음 온 유저도 3분 안에 첫 봇전을 시작할 수 있어야 한다.
- 랭크 유저는 30초 안에 빠른대전 큐에 들어갈 수 있어야 한다.
- 5판 3선승이 복잡하게 느껴지지 않아야 한다.
- 카드 이미지와 코스메틱이 게임의 주인공처럼 보여야 한다.
- 치카포 본편 자산이 전투력이 아니라 외형/정체성으로 쓰인다는 점이 명확해야 한다.
- 모바일에서도 덱 편성과 리플레이가 가능해야 한다.

## 5. 덱 편성

### 5.1 기본 목표

덱 편성은 전투 전에 유저가 보유 카드 중 실제 대전에 사용할 후보를 정하는 화면이다. 사전 편성에서는 카드 추가/제거와 덱 저장만 제공하고, 라운드별 출전 카드, 배치, 전술 성향, 타겟 우선순위는 게임이 잡힌 뒤 각 라운드마다 인게임에서 직접 선택한다.

MVP 규칙:

```text
덱 크기: 6~10장
라운드별 출전: 최대 6장
보드: 2행 x 4열
사전 라운드 플랜 편집: 노출하지 않음
같은 스트리머 중복 금지
보유하지 않은 카드 편성 금지
```

서버는 덱 저장 시 기본 라운드 플랜을 내부 fallback으로 자동 생성할 수 있다. 이 값은 유저가 사전에 편집하는 전략 요소가 아니라, 라운드 선택 타이머가 만료되거나 재접속 중 입력이 없을 때 UX를 끊지 않기 위한 안전장치다.

### 5.2 화면 구성

PC:

```text
왼쪽/상단: 저장 덱 목록과 대전 시작 버튼
중앙: 덱 편집기
오른쪽/하단: 보유 카드 선택 목록, 덱 검증 상태
```

모바일:

```text
상단: 덱 이름, 저장 상태
중앙: 선택된 덱 카드
하단: 보유 카드 드로어
플로팅: 저장/검증/큐 버튼
```

필터:

- 최근 사용
- 추천순

### 5.4 인게임 라운드 선택 UX

라운드별 선택은 매치가 생성된 뒤 진행 중인 게임 화면에서만 제공한다. 유저는 라운드가 끝날 때마다 다음 라운드의 출전 카드와 전술을 다시 고른다.

선택 항목:

```text
출전 카드: 저장 덱 안에서 최대 6장
formation: 2x4 보드 배치
tactic_style: 균형 / 공격적 / 방어적 / 후열 압박 / 전열 붕괴
focus_rule: 낮은 체력 / 후열 우선 / 표식 대상 / 전열 우선
strategy_chip: 덱 또는 라운드 선택에서 허용된 전술 칩
```

기본 선택 제한 시간은 60초다. 시간 안에 선택하지 않으면 서버가 저장된 기본 플랜 또는 직전 유효 선택으로 자동 진행한다. 이 자동 진행은 탈주나 잠수로 상대 경험이 망가지지 않게 하기 위한 처리이며, 유저에게 불필요한 패널티 문구로 표시하지 않는다.

### 5.5 덱 검증

저장 전 검증:

- 보유 카드 여부
- 카드 수 6~10장
- 중복 스트리머 카드
- 비활성 카드
- 아레나 사용 가능 여부
- 금지 조합

검증 결과 표시:

- 사용 가능
- 경고 있음
- 사용 불가

경고 예:

- 전열 후보 카드가 부족합니다.
- 회복은 많지만 피해가 부족합니다.
- 비활성화된 카드가 포함되어 덱을 수정해야 합니다.

## 6. 빠른대전

### 6.1 진입 흐름

1. 유저가 덱 선택
2. 덱 검증
3. 빠른대전 버튼 클릭
4. 큐 등록
5. 매칭 대기
6. 매칭 완료
7. 세트 리플레이 진입

### 6.2 매칭 대기 화면

표시:

- 선택 덱
- 현재 티어
- 예상 대기 시간
- MMR 범위 확장 안내
- 취소 버튼
- 봇 연습전으로 전환 버튼. 일정 시간 이후

SSE/fallback 상태 조회:

- 최소 2~3초 간격
- 화면 이탈 시 아직 매칭 전이면 큐 유지 여부를 확인한다.
- 앱 백그라운드 진입 시 아직 매칭 전이면 큐 취소 또는 제한을 안내한다.
- 연결이 끊겨도 클라이언트가 즉시 취소 write를 반복하지 않고, 서버 TTL과 다음 상태 조회로 정리한다.
- 반복 취소나 반복 만료는 짧은 재큐 쿨다운 대상이 될 수 있음을 안내한다.

### 6.3 매칭 완료

표시:

- 상대 닉네임
- 상대 티어
- 양쪽 대표 카드
- 매치 형식: 5판 3선승
- 라운드 전술 선택 버튼

이미 확정된 라운드는 match id로 다시 조회할 수 있어야 한다. 네트워크가 끊긴 경우 아직 확정하지 않은 다음 라운드부터 이어서 선택하게 하며, 임의 항복이나 패배 회피로 처리하지 않는다.

매칭 완료 후 이탈 UX:

- 상대가 브라우저를 닫아도 내 화면은 대기 상태로 멈추지 않는다.
- 한쪽이 라운드 전술을 제출하면 기본 선택 타이머 동안 상대 입력을 기다린다.
- 타이머가 끝나도 상대가 제출하지 않으면 저장된 기본 라운드 플랜으로 자동 진행한다.
- 전투 화면의 `나가기`는 결과 포기나 항복이 아니라 화면 종료로 처리한다.
- 재접속 시 진행 중인 매치가 있으면 다음 미확정 라운드 선택 CTA를 노출한다.
- 상대 미접속 여부, 상대 리플레이 시청 여부는 노출하지 않는다. 불필요한 감정 유발을 막기 위해서다.

라운드 결과 공개:

- 라운드 시작 버튼을 누른 직후 승패, 점수, 세트 결과를 먼저 보여주지 않는다.
- 클라이언트는 짧은 전투 재생 상태를 표시한 뒤 라운드 종료 시 결과 배너를 공개한다.
- 서버 응답은 이미 도착해 있더라도 UI는 `전투 중 -> 라운드 종료 -> 다음 전술 선택` 순서를 지킨다.

## 7. AI 봇 연습전

### 7.1 목적

봇전은 학습과 덱 테스트용이다.

봇전은 MMR과 랭킹에 반영하지 않는다.

### 7.2 봇전 선택 화면

난이도:

- 입문
- 일반
- 상급
- 메타 연습

형식:

- 빠른 단판
- 표준 5판 3선승

추천:

- 튜토리얼: 빠른 단판
- 덱 테스트: 5판 3선승

### 7.3 봇전 결과

표시:

- 승패
- 덱 약점
- 추천 수정
- 주요 카드 기여도
- 다시 하기
- 같은 덱으로 빠른대전

## 8. 세트 리플레이

### 8.1 목적

리플레이는 이미 계산된 세트 전투를 7~12분 체감으로 보여준다.

필수 UX:

- 매치 스코어
- 현재 라운드
- 라운드 전환
- 카드 체력/에너지
- 스킬 컷인
- 상태이상
- 피해/회복 숫자
- 라운드 승자
- 세트 승자

### 8.2 화면 구성

상단:

- Player A
- 세트 스코어
- Player B
- Round 표시
- 재생 속도

중앙:

- 2행 x 4열 양쪽 보드
- 카드 이미지
- 체력/에너지 바
- 상태 아이콘

하단:

- 이벤트 타임라인
- 라운드 이동
- 결과만 보기 또는 둘 다 스킵
- 다시보기

### 8.3 재생 옵션

- 1x
- 1.25x
- 1.5x
- 2x
- 라운드 건너뛰기
- 결과만 보기 또는 둘 다 스킵
- 마지막 라운드만 보기

모바일 기본값은 1.5x를 권장한다.

### 8.4 라운드 전환

라운드 사이:

- 라운드 결과
- 라운드 MVP
- 현재 세트 스코어
- 다음 라운드 플랜 이름

전환 시간:

```text
8~12초
```

유저는 전환을 건너뛸 수 있어야 한다.

- 주요 스킬 발동 횟수

### 9.3 패배 원인 요약

자동 요약 예:

- 후열이 빠르게 무너졌습니다.

- 상대 `control` 태그에 스킬 발동이 지연되었습니다.
- 2라운드 플랜이 1라운드와 같아 카운터 대응이 부족했습니다.

MVP에서는 규칙 기반 요약으로 충분하다.

필수 정보:

- 카드 이미지
- 스트리머 이름
- 역할군
- 클래스
- 스탯 프로필
- 액티브 스킬
- 패시브 스킬
- 시너지 태그
- 아레나 사용 가능 여부
- 시즌 사용 가능 여부

- 치카포 시세 기반 전투력
- 팔로워 기반 전투력
- 방송 중 버프

### 10.2 카드 상세

카드 상세 탭:

- 기본 정보

## 15. 접근성 및 모바일 기준

모바일:

- 카드 텍스트는 너무 작지 않게
- 보드는 핀치 확대 없이 읽을 수 있어야 함
- 스킬 설명은 bottom sheet로 제공
- 리플레이는 1.5x 기본 재생 권장
- 봇전은 결과만 보기, PvP는 둘 다 스킵 버튼을 항상 노출

접근성:

- 상태이상은 색만으로 구분하지 않음
- 아이콘과 텍스트 병행
- 숫자 변화는 색과 부호 동시 사용
- 긴 애니메이션은 건너뛰기 가능

## 16. 빈 상태와 오류 상태

덱 없음:

- 추천 덱 생성 버튼
- 카드 도감으로 이동

매칭 실패:

- 다시 시도
- 봇 연습전
- 큐 취소

카드 비활성화로 덱 사용 불가:

- 비활성 카드 표시
- 대체 카드 추천
- 덱 수정으로 이동

리플레이 만료:

- 요약 결과 표시
- 상세 리플레이는 보존 기간 만료 안내

## 18. 반드시 지켜야 할 결정 사항

1. 빠른대전은 5판 3선승 세트 매치로 표현한다.
2. 라운드별 전술 플랜은 고급 기능으로 제공하되, 신규 유저는 공통 플랜 하나로 시작할 수 있어야 한다.
3. 서버는 매치를 7~12분 동안 붙잡고 있지 않고, 클라이언트가 리플레이로 7~12분 체감을 만든다.
4. 봇전 결과만 보기, PvP 둘 다 스킵, 완료 리플레이 라운드 건너뛰기를 반드시 제공한다.
5. 치카포 본편 자산은 전투력이 아니라 외형과 정체성으로 표현한다.
6. opt-out은 스트리머가 쉽게 찾고 실행할 수 있어야 한다.
7. 랭킹은 아레나 전용이며 스냅샷 기반으로 표시한다.

## 19. 실제 게임 페이지 상용 UX 기준

### 19.1 전투 전

- 유저는 상단 HUD에서 현재 라운드, 스코어, 목표 승수, 준비 상태를 바로 확인한다.
- 출전 카드 편성은 전장 아래에서 진행하고, 전투 시작 후에는 전술/출전 변경 입력을 잠근다.
- 상대가 아직 선택하지 않았을 때는 상대 접속 상태를 불안하게 노출하지 않고, 타이머와 기본 진행 가능 여부만 보여준다.

### 19.2 전투 중

- 전투 중에는 최종 결과와 긴 전투 로그를 숨긴다.
- Pixi 전장 중앙 HUD는 현재 행동자, 대상, 행동 타입, 턴 진행률을 표시한다.
- 한 턴에 한 행동만 강하게 보여주며, 행동과 무관한 카드는 낮은 강조도로 뒤에 배치한다.
- HP 0 또는 `DEATH` 반영 카드는 이후 행동자처럼 보이면 안 된다.
- 봇전의 `결과만 보기`는 서버 재계산 없이 이미 받은 라운드 리플레이의 마지막 상태로 이동하는 클라이언트 전용 조작으로 제공한다.
- PvP 진행 중 스킵은 한쪽 플레이어만 먼저 결과를 보는 경험을 막기 위해 `둘 다 스킵`으로 제공한다. 양쪽 플레이어가 모두 스킵했을 때만 결과 화면으로 이동하며, 동의 상태는 `/arena/realtime`의 휘발성 메모리로만 처리하고 DB에 저장하지 않는다.

### 19.3 전투 후

- 라운드 종료 후에만 라운드 결과와 리플레이 로그를 표시한다.
- 세트 종료 시에는 결과 모달을 우선 표시한다.
- 완료된 경기는 라운드별 리플레이 선택, 배속 재생, 관전 링크 공유가 가능해야 한다.
- 완료 리플레이는 처음부터 재생과 마지막 장면 이동을 모두 제공한다.

### 19.4 모바일

- 모바일은 데스크톱 축소판이 아니라 전장 중심 화면으로 보인다.
- 로그와 부가 패널은 전장 아래로 밀리며, 전장과 주요 CTA를 가리지 않는다.
- 툴팁은 화면 경계에 맞춰 위치를 보정한다.

## 20. 확장 UX: 5판 3선승, 8인 컵, 관전, 관리자

### 20.1 5판 3선승 전략 편성

덱 편성 화면은 단순히 6장을 고르는 화면이 아니라 10장 덱과 5개 라운드 플랜을 관리하는 전략 화면이어야 한다.

필수 UX:

- 덱 10장 슬롯
- 라운드별 출전 6장 표시
- 예비 카드 4장 표시
- 1~5라운드 탭
- 라운드별 전술 선택 편집
- 전술 칩 1개 선택
- 전장 규칙 설명
- 덱 검증 결과와 금지 조합 안내

금지 UX:

- 밴픽 화면
- 라운드 사이 무제한 선택 대기
- 상대 접속 상태를 전투 진행 조건처럼 보여주는 UI
- 시즌 로테이션 카드 풀처럼 일부 카드만 열리는 안내

### 20.2 8인 컵 UX

8인 컵은 별도 모드로 진입한다.

화면 흐름:

1. 컵 모드 선택
2. 컵 전용 덱/전술 플랜 확인
3. 컵 큐 등록
4. 8명 모집 상태 표시
5. 컵 생성 후 브래킷 표시
6. 내 경기 결과와 하이라이트 표시
7. 최종 1~8위 결과 표시
8. 컵 포인트와 이벤트 랭킹 표시

컵은 기본 랭크 MMR과 분리해 보여준다.

### 20.3 관전 UX

관전은 완료된 리플레이 관전으로 시작한다.

- 공개 매치 리플레이 목록
- 공개 컵 하이라이트
- 스트리머/관리자 선정 경기
- 공유 링크로 입장
- 결과 스포일러 숨김 토글
- 1.5x/2x 재생
- 핵심 라운드만 보기

실시간 관전방처럼 보이는 UI는 만들지 않는다. 이미 계산된 리플레이를 함께 보는 경험으로 표현한다.

### 20.4 관리자 페이지 UX

아레나 관리자 페이지는 치카포 기존 관리자 페이지와 같은 레이아웃 원칙을 따르되, 아레나 전용 탭을 가진다.

탭:

- 운영 현황
- 매치/큐
- 8인 컵
- 관전/리플레이
- 카드 사용 가능 상태
- 클래스/스킬/태그 통계
- 전술 칩/전장 규칙 통계
- 위험 조합
- 랭킹/통계 스냅샷
- kill switch
- 감사 로그

관리자 통계 화면은 최신 스냅샷 시각, 표본 수, 신뢰도, 갱신 버튼을 반드시 표시한다.
