# 치카포 아레나 권리, 약관, 스트리머 이미지 사용 정책

## 1. 목적

이 문서는 치카포 아레나에서 스트리머 이미지, 카드 이미지, 이름, 코스메틱 리소스를 사용할 때 필요한 권리 처리와 운영 기준을 정의한다.

아레나는 치카포 본편의 리소스를 활용하는 자매 서비스이지만, 별도의 게임 서비스로 보일 수 있다. 따라서 “치카포에 등록된 이미지니까 자동으로 사용 가능하다”가 아니라, 고지, 선택권, 제한 요청, 이의 처리 기준을 명확히 둔다.

## 2. 기본 원칙

- 전투력은 이미지, 시세, 후원, 방송 여부와 연결하지 않는다.
- 스트리머 이미지는 카드 초상, 카드 아트, 리플레이 컷인, 도감 표시 등 코스메틱 용도로만 사용한다.
- 스트리머는 자신의 카드가 아레나에 사용되지 않도록 비활성화할 수 있다.
- 비활성화는 치카포 본편의 카드 거래/수집 상태와 분리한다.
- 이미 종료된 경기 결과는 경기 무결성을 위해 유지할 수 있다.
- 비활성화 후 신규 매치, 신규 덱, 봇 덱, 추천 덱에는 등장하지 않는다.

## 3. 약관과 사전 고지

아레나 출시 전 치카포 서비스 고지 또는 약관에 아래 내용을 포함한다.

필수 고지:

- 치카포 등록 이미지와 카드 코스메틱이 아레나 카드 표현에 사용될 수 있음
- 아레나는 치카포 본편과 분리된 게임 서비스임
- 전투 능력은 치카포 경제 데이터와 무관함
- 스트리머는 아레나 카드 비활성화를 요청할 수 있음
- 비활성화 후에도 과거 경기 기록은 무결성을 위해 보존될 수 있음
- 공개 리플레이는 별도 정책에 따라 제공되며 MVP에서는 기본 비공개임

권장 UX:

- 아레나 최초 접속 시 별도 안내 모달
- 스트리머 관리 페이지에 “아레나 카드 사용 상태” 표시
- 비활성화 신청 경로 상시 노출
- 시즌 공지에 권리/비활성화 정책 반복 고지

## 4. 이미지 사용 범위

허용 범위:

- 카드 초상화
- 카드 도감
- 덱 편성 화면
- 매치 결과 화면
- 본인 리플레이
- 시즌 통계의 카드 표시
- MVP 하이라이트
- 코스메틱 카드 프레임 또는 이름 효과

추가 검토가 필요한 범위:

- 외부 공유용 이미지
- 제3자 공개 리플레이
- 광고 소재
- 유료 상품 상세 페이지
- 시즌 대표 배너
- SNS 자동 공유 이미지

MVP에서는 추가 검토 범위 기능을 넣지 않는다.

## 5. 비활성화 처리 기준

비활성화 신청자는 본인 확인을 거친 스트리머 또는 권리 대리인으로 제한한다.

처리 SLA:

```text
접수 확인: 3영업일 이내
신규 매치 제외: 본인 확인 후 가능한 즉시
도감/리플레이 제한 표시: 최대 7영업일 이내
분쟁성 요청: 운영자 검토 후 별도 안내
```

즉시 적용:

- 신규 빠른대전 카드 풀 제외
- 신규 봇 덱 제외
- 추천 카드 제외
- 랜덤 덱 생성 제외

정책에 따라 제한 표시:

- 과거 매치 리플레이
- 과거 전적
- 시즌 통계
- 밸런스 집계

## 6. 재활성화 처리 기준

재활성화는 신규 카드 사용 가능 상태 갱신 또는 다음 시즌부터 반영한다.

이유:

- 시즌 중 카드 풀 안정성 유지
- 덱 검증 캐시 무효화 최소화
- 매칭/밸런스 혼란 방지
- 반복 opt-out/in 악용 방지

재활성화 조건:

- 본인 확인
- 현재 시즌 정책 동의
- 카드 능력 버전 확인
- 금지 조합 검증 통과

## 7. 대체 표시 정책

비활성화된 카드는 아래 우선순위로 표시한다.

1. 카드 이미지 제거 후 기본 대체 이미지
2. 카드명 “비활성화된 카드” 표시
3. 도감 비공개 처리
4. 리플레이에서 카드 초상 대체

유지 가능 정보:

- 경기 결과
- 라운드 결과
- MMR 변화
- 카드 역할군 또는 익명화된 전투 단위

노출하지 않는 정보:

- 원본 이미지
- 원본 카드명
- 외부 공유 가능한 원본 리플레이 썸네일

## 8. 관리자 처리 로그

모든 권리 요청은 로그를 남긴다.

필드:

```text
request_id
channel_id
requester_type
verification_method
request_type
requested_scope
status
handled_by
handled_at
memo
before_state
after_state
```

로그는 최소 1년 이상 보관한다.

## 9. 출시 전 필수 조건

정식 시즌 전 반드시 완료한다.

- 약관 또는 공지 문구 확정
- 스트리머 비활성화 신청 경로 공개
- 본인 확인 절차 확정
- 대체 이미지 준비
- 비활성화 E2E 테스트 통과
- 과거 리플레이 제한 표시 테스트 통과
- 관리자 처리 로그 확인

## 10. 금지 사항

- 비활성화 요청을 받은 카드를 신규 매치에 계속 노출
- 스트리머 이미지가 포함된 공개 광고 소재를 별도 검토 없이 사용
- 공개 리플레이에서 비활성화된 카드 이미지를 계속 노출
- 비활성화 요청을 이유 없이 장기간 방치
- 권리 요청 로그를 남기지 않음
