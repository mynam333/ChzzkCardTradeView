# 치카포 아레나 커뮤니케이션 템플릿

## 1. 목적

이 문서는 치카포 아레나의 공지, 패치노트, 장애 안내, 시즌 안내, 스트리머 카드 관련 안내문을 일관된 기준으로 작성하기 위한 템플릿이다.

아레나는 본편 치카포와 연결된 자매 서비스이므로, 모든 안내는 다음 원칙을 지킨다.

- 전투력은 후원, 시세, 방송 여부, 포인트, 보유 카드 수와 연결되지 않는다.
- 치카포에서 가져오는 데이터는 이미지와 코스메틱 중심이다.
- 스트리머는 자신의 카드가 아레나에 사용되지 않도록 비활성화할 수 있다.
- 아레나는 별도 MMR과 랭킹을 가진다.
- 서버 안정성이 최우선이며, 장애 시 본편 보호를 위해 일부 기능이 즉시 제한될 수 있다.

## 2. 공통 작성 규칙

모든 공지는 아래 정보를 우선 포함한다.

```text
제목:
적용 일시:
영향 범위:
사용자에게 필요한 행동:
변경되지 않는 것:
상세 내용:
추가 안내:
```

작성 규칙:

- 날짜와 시간은 KST 기준으로 표기한다.
- 장애 또는 점검 공지는 실제 영향 범위를 과장하지 않는다.
- 밸런스 패치 공지는 변경 이유와 기대 효과를 함께 적는다.
- 보상 공지는 지급 대상, 지급 시점, 미지급 문의 기준을 분리한다.
- 스트리머 카드 관련 공지는 권리와 선택권을 명확히 설명한다.
- “전투력에 영향을 주지 않는다”는 원칙이 필요한 경우 반복해서 명시한다.

## 3. 시즌 오픈 공지

```text
[치카포 아레나] 시즌 {시즌명} 오픈 안내

적용 일시: {YYYY-MM-DD HH:mm} KST

치카포 아레나 시즌 {시즌명}이 시작됩니다.

이번 시즌부터 플레이어는 치카포 이미지 리소스를 기반으로 구성된 스트리머 카드 덱으로 빠른대전과 연습게임을 플레이할 수 있습니다.
아레나의 전투력은 방송 여부, 후원, 시세, 포인트, 카드 보유 수량과 연결되지 않습니다.

주요 내용:
- 빠른대전: 5판 3선승 세트 매치
- 평균 플레이 체감 시간: 7~12분
- 랭킹: 아레나 전용 MMR 기준
- 연습게임: AI 봇 상대 가능
- 카드 능력: 스트리머 직접 설정 또는 고정 랜덤 템플릿
- 스트리머 카드 비활성화: 원하지 않는 스트리머는 카드 사용을 중지할 수 있음

시즌 기간:
- 시작: {YYYY-MM-DD HH:mm} KST
- 종료: {YYYY-MM-DD HH:mm} KST

랭킹 보상:
- {보상 설명}

변경되지 않는 것:
- 치카포 본편 카드 시세는 아레나 전투력에 영향을 주지 않습니다.
- 방송 중 여부는 전투력에 영향을 주지 않습니다.
- 유료 상품은 전투력에 영향을 주지 않습니다.
```

## 4. 베타 테스트 모집 공지

```text
[치카포 아레나] 베타 테스트 안내

테스트 기간: {YYYY-MM-DD HH:mm} ~ {YYYY-MM-DD HH:mm} KST

치카포 아레나의 안정성, 밸런스, 매칭 품질을 확인하기 위한 베타 테스트를 진행합니다.

테스트 범위:
- 빠른대전
- AI 연습게임
- 덱 편성
- 리플레이
- 아레나 랭킹

테스트 중 제한 사항:
- 일부 카드 능력은 임시 템플릿으로 제공될 수 있습니다.
- 밸런스 패치가 예고 없이 적용될 수 있습니다.
- 장애 발생 시 아레나 기능이 일시 중단될 수 있습니다.
- 테스트 랭킹은 정식 시즌으로 이전되지 않을 수 있습니다.

중요 원칙:
- 베타 중에도 후원, 시세, 방송 여부, 포인트는 전투력에 반영되지 않습니다.
- 스트리머가 비활성화한 카드는 아레나 신규 매치에 등장하지 않습니다.
```

## 14. 문구 검수 체크리스트

공지 발행 전 아래 항목을 확인한다.

- 날짜와 시간이 KST로 표기되어 있는가?
- 영향 범위가 기능별로 분리되어 있는가?
- 치카포 본편 영향 여부를 명시했는가?
- 전투력과 유료/시세/방송 데이터가 연결되지 않는다고 필요한 곳에 명시했는가?
- 스트리머 권리와 비활성화 정책을 오해 없이 설명했는가?
- 보상 지급 조건과 예외 조건이 분리되어 있는가?
- 장애 공지의 경우 원인 추정과 확정 사실을 구분했는가?
- 랭킹 보정 공지의 경우 이미 종료된 매치 처리 기준을 설명했는가?
