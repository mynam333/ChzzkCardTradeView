# 치카포 아레나 화면별 UX 와이어프레임

- 문서 버전: v1.0.0-rebuild
- 기준일: 2026-07-06
- 상위 문서: `CHIKAPO_ARENA_GDD.md`
- 목적: 새 아레나의 핵심 화면 구조, 상태, 사용자 흐름을 구현 가능한 수준으로 정의한다.

---

## 1. 공통 UX 원칙

- 첫 화면은 플레이 가능한 기능을 바로 보여준다.
- 설명은 위키로 보내되, 실수 순간에는 짧은 인라인 도움말을 제공한다.
- 모바일에서도 필드, 손패, 코스트, 시간, 체력이 동시에 읽혀야 한다.
- 모든 핵심 행동은 서버 검증 결과와 동기화되어야 한다.
- 상대 비공개 정보는 UI에 추정 형태로도 노출하지 않는다.
- 상용 게임처럼 보이되, 전투 판정 가독성이 항상 우선이다.

### 4.2. 모바일

```text
┌──────────────────────┐
│ 덱 이름 / 저장       │
├──────────────────────┤

│ 코스트 곡선          │
├──────────────────────┤
│ 필터 바              │
├──────────────────────┤
│ 카드 목록            │

```

### 4.3. 검증 표시

필수 오류:

- 덱 14장 미만
- 덱 20장 초과
- 동일 스트리머 2장 이상
- 비활성 카드 포함
- 공식 모드 불가 카드 버전 포함

권장 경고:

- 1~3코스트 카드가 4장 이하
- 8~9코스트 카드가 5장 이상
- 클래스가 3종 이하
- 직접 공격 카드가 너무 적음
- 전열 후보가 너무 적음

```text
├──────────────────────────────────────────────────────────┤
│ 내 전열:   [좌] [중] [우]                                │

├──────────────────────────────────────────────────────────┤

├──────────────────────────────────────────────────────────┤
│ [배치] [전술 이동] [교체] [묘지] [위키] [완료]            │
└──────────────────────────────────────────────────────────┘
```

### 7.2. 모바일

```text
┌──────────────────────┐
│ 상대 체력 / 시간     │
├──────────────────────┤
│ 상대 필드 2x3        │
├──────────────────────┤
│ 내 필드 2x3          │
├──────────────────────┤
│ 코스트 / 이동 / 묘지 │
├──────────────────────┤
│ 손패 가로 스크롤     │
├──────────────────────┤
│ 행동 바 / 완료       │
└──────────────────────┘
```

### 7.3. 행동 UX

| 행동 | UX |
|---|---|
| 배치 | 손패 카드 드래그 또는 카드 선택 후 칸 선택 |
| 전술 이동 | 필드 카드 선택 -> 빈 칸 선택 |
| 교체 | 손패 카드 선택 -> 기존 카드 칸 선택 -> 경고 확인 |
| 완료 | 서버 검증 후 확정 |
| 취소 | 확정 전 임시 행동 초기화 |

### 7.4. 오류 표시

- 코스트 부족
- 이미 사용한 전술 이동
- 이번 턴 배치한 카드 이동 시도
- 이번 턴 배치한 카드 교체 대상 시도
- 같은 칸 중복 배치
- 손패에 없는 카드 제출

## 8. 전투 화면

```text
┌────────────────────────────────────────────┐
│ 상단 HUD: 상대 체력 / 직접 피해 표시       │
├────────────────────────────────────────────┤
│ PixiJS 전투 캔버스                         │
│ - 상대 필드                                │
│ - 라인                                     │
│ - 내 필드                                  │
│ - 공격/VFX/피해 숫자                       │
├────────────────────────────────────────────┤
│ 하단 HUD: 내 체력 / 로그 요약 / 속도        │
└────────────────────────────────────────────┘
```

재생 상태:

- 배치 공개
- 전투 시작
- 전열 공격
- 후열 공격
- 전투 종료
- 턴 결과
- 스킵
- 1x/1.5x/2x
- reduced motion

가독성 기준:

- 피해 숫자는 1초 안에 사라진다.
- 큰 피해는 크기와 색으로 구분한다.
- 보호막 흡수는 체력 피해와 색이 다르다.
- 직접 공격은 플레이어 체력 UI와 연결된다.
- 전투불능 카드는 묘지 이동 방향으로 사라진다.
