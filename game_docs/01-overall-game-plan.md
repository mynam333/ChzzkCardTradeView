# 치카포 프론티어: 게임 전체 기획

## 1. 서비스 개요

`치카포 프론티어`는 치카포의 카드 수집 경험을 게임 유닛 기반 RPG로 확장하는 신규 서비스다.

기존 치카포에서 카드는 수집, 거래, 시세 확인, 강화, 대표 카드 설정의 의미를 가진다. 프론티어에서는 여기에 `역할`, `스킬`, `파티 편성`, `원정`, `시즌 기여`의 의미를 추가한다.

가장 중요한 차별점은 스트리머 참여다. 스트리머는 본인 채널 카드의 클래스와 빌드를 직접 선택한다. 유저는 그렇게 만들어진 스트리머 카드를 모아 자신만의 파티를 구성한다.

## 2. 목표

- 치카포의 카드 수집 이유를 강화한다.
- 특정 고가 카드만 쓰이는 구조가 아니라 다양한 스트리머 카드가 쓰이게 한다.
- 스트리머가 자기 카드에 개성을 부여할 수 있게 한다.
- 방치형 RPG로 시작하되 보스 레이드, 오토리그, 지역 점령전으로 확장 가능하게 만든다.
- 서버 부하를 낮게 유지한다.
- 기존 포인트 경제를 해치지 않는 별도 성장 재화를 설계한다.

## 3. 핵심 플레이어

### 3.1 스트리머

스트리머는 자기 카드의 게임 내 정체성을 설정한다.

- 클래스 선택
- 능력치 배분
- 패시브 2개 선택
- 카드 클래스 배지 노출
- 시즌 중 제한적 변경

스트리머가 적극적으로 참여하지 않아도 서비스가 멈추면 안 된다. 미설정 스트리머는 기본 추천 빌드를 자동 적용한다.

### 3.2 유저

유저는 클래스가 부여된 카드를 수집하고 파티를 편성한다.

- 보유 카드로 원정 파티 편성
- 모든 지역에서 필요한 전투/생존/상태/탐사/변수 축을 고려해 조합
- 원정 결과 수령
- 시즌 점수와 재료 획득
- 주간 보스/오토리그/점령전 참여

### 3.3 관리자

관리자는 클래스, 패시브, 시즌, 보상, 밸런스를 조정한다.

- 클래스 활성/비활성
- 패시브 점감/상한 규칙 관리
- 시즌별 희소 클래스 보너스
- 보스/지역별 판정 축 비중 설정
- 보상 총량 모니터링

## 4. 핵심 루프

1. 스트리머가 자기 카드 빌드를 설정한다.
2. 유저가 카드 뽑기, 마켓, 교환으로 카드를 모은다.
3. 유저가 카드 3~5장으로 파티를 편성한다.
4. 파티를 원정 지역에 보낸다.
5. 일정 시간이 지나면 결과를 수령한다.
6. 재료, 시즌 점수, 장비 파편, 포인트성 보조 재화 등을 획득한다.
7. 획득한 재료로 프론티어 전용 성장 요소를 강화한다.
8. 더 높은 난도 원정, 주간 보스, 오토리그로 확장한다.

## 5. 기본 장르 방향

1차 장르는 `비동기 방치형 원정 RPG`다.

방치형이지만 계속 켜두는 게임이 아니다. 유저는 파티를 보내고 나중에 돌아와 결과를 받는다.

서버는 아래 방식으로 동작한다.

- 원정 시작 시 파티 스냅샷 저장
- 원정 종료 예정 시각 저장
- 결과 수령 시 seed 기반으로 결과 계산
- 중간 tick 없음
- 진행 중 원정은 DB row 하나로 표현

## 6. 기존 치카포 시스템과의 연결

### 6.1 카드

카드는 프론티어의 유닛이다.

- 스트리머: 유닛 정체성
- 별 등급: 성장 보정
- 시리얼: 수집 가치
- 코스메틱: 시각적 개성
- 클래스 빌드: 전투/원정 역할

### 6.2 스트리머 커스텀 이미지

프론티어에서는 카드 이미지가 파티 UI, 원정 결과, 전투 로그, 보스 기여 화면에 노출된다.

이미지가 부적절할 경우 기존 신고/블라인드/관리자 초기화 정책을 그대로 따라야 한다.

### 6.3 시세

시세는 기존 치카포의 경제/랭킹 정보로 유지하지만 프론티어 성능에는 반영하지 않는다.

프론티어에서 시세가 영향을 주지 않는 항목:

- 전투력
- 원정 성공률
- 보상량
- 파티 코스트
- 추천 파티
- 클래스/패시브 효율

시세는 카드 상세, 마켓, 기존 랭킹 화면에서만 의미를 가진다. 프론티어는 경제 가치가 아니라 클래스 빌드, 별 등급, 능력치 배분, 패시브, 파티 조합으로 성능을 만든다.

### 6.4 별 등급

별 등급은 카드의 클래스 정체성을 바꾸지 않는다. 대신 계수와 연출, 작은 보너스를 제공한다.

- 0성: 기본 기능
- 1성: 주요 스탯 소폭 증가
- 2성: 기본 행동 계수 증가
- 3성: 패시브 효과 소폭 증가
- 4성: 역할군 시너지 증가
- 5성: 클래스 전용 연출과 작은 고유 보너스

### 6.5 마켓/교환

프론티어는 마켓 수요를 다양화한다.

기존에는 인기/시세/별 등급 중심이었다면, 프론티어 이후에는 시세와 별개로 아래 수요가 생긴다.

- 특정 클래스 카드
- 특정 패시브 조합 카드
- 희소 역할군 카드
- 보스 시즌의 판정 축에 잘 맞는 카드
- 원정 보상형 카드

## 7. 콘텐츠 확장 구조

### 7.1 방치형 원정

1차 메인 콘텐츠.

- 파티 편성
- 지역 선택
- 원정 시간 선택
- 결과 수령
- 보상/시즌 점수 획득

### 7.2 주간 보스 레이드

2차 콘텐츠.

- 하루 제한 횟수 공격
- 서버 전체 공동 HP
- 클래스별 기여 랭킹
- 보스별 판정 축 비중 순환

### 7.3 비동기 오토리그

3차 경쟁 콘텐츠.

- 방어 파티 등록
- 공격 대상 매칭
- 서버 전투 1회 시뮬레이션
- 전투 로그/리플레이 제공
- 점감/상한과 시즌 룰 운영

### 7.4 지역 점령전

커뮤니티형 시즌 콘텐츠.

- 지역별 탐사 점수 누적
- 유저 파티 기준 기여
- 특정 스트리머 팬덤 간 직접 충돌을 피하는 표현 사용
- 개인 보상과 전체 달성 보상 분리

### 7.5 로그라이트 던전

장기 확장 후보.

- 클래스가 시작 덱 또는 스킬 카드 풀을 결정
- 패시브가 이벤트 선택지에 영향
- 서버 부담은 낮지만 클라이언트 구현량이 크다

## 8. 경제 설계 원칙

프론티어는 기존 포인트 경제를 직접 흔들면 안 된다.

권장 재화:

- `탐사 재료`: 원정 성장용
- `프론티어 토큰`: 시즌 상점용
- `장비 파편`: 파티 보조 장비 제작용
- `조사 점수`: 시즌 랭킹용, 재화 아님

포인트 보상은 소량 또는 이벤트성으로 제한한다.

금지:

- 원정만으로 대량 포인트 무한 생산
- 기존 마켓 경제와 시세를 흔드는 보상 난사
- 보상형 패시브 중첩의 점감/상한 누락으로 기대값 폭증

## 9. 1차 MVP

1차 목표는 “클래스가 있는 카드로 원정을 보내고 결과를 받는 재미”를 검증하는 것이다.

포함:

- 스트리머 클래스 설정
- 클래스 24종
- 패시브 48종
- 능력치 20포인트 배분
- 유저 파티 4장 편성
- 원정 지역 5개
- 원정 시간 4종
- 원정 결과 정산
- 시즌 점수
- 간단한 역할군 도감

제외 또는 베타:

- 실시간 전투
- 풀 리플레이
- 정식 오토리그
- 길드/팬덤전
- 복잡한 장비 강화
