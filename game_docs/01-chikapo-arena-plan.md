# 치카포 아레나 기획서

## 1. 개요

치카포 아레나는 치카포에 등록된 스트리머 카드 이미지를 기반으로 하는 독립형 자매 서비스다. 기존 치카포의 카드 이미지, 커스텀 이미지, 카드 테두리, 이름 효과, 칭호성 코스메틱을 활용하되, 전투력은 치카포의 시세, 팔로워 수, 방송 중 여부, 채팅량, 보유 자산과 분리한다.

목표는 약 3,000명 규모의 등록 스트리머가 각각 고유한 클래스, 스탯, 스킬, 시너지 조합을 가진 카드로 등장하는 시즌제 카드 오토배틀러를 만드는 것이다. 각 카드는 고유하고 컨셉추얼해야 하지만, 경쟁 모드의 공정성을 위해 모든 능력은 밸런스 가능한 템플릿과 파워 예산 규칙 안에서 생성된다.

## 2. 핵심 원칙

### 2.1 현재 리소스만으로 가능한 표현 방식

현재 리소스로 상용 수준을 목표로 하려면 캐릭터 스프라이트 오토체스가 아니라 프리미엄 카드 오토배틀러로 설계해야 한다.

- 스트리머 이미지: 유닛 초상화
- 커스텀 카드 이미지: 고유 카드 아트
- 카드 테두리: 등급감, 시즌 스킨, 전투 중 강조 프레임
- 이름 효과: 카드명 연출, 리플레이 컷인, MVP 연출
- 칭호/코스메틱: 프로필, 덱 표식, 시즌 보상
- 전투 연출: 카드 흔들림, 확대 컷인, 타격선, 파티클, 숫자 플로팅, 상태 아이콘, 보드 이펙트

금지 방향:

- 캐릭터가 직접 걸어다니고 공격 모션을 수행하는 스프라이트 기반 전투
- 스트리머 이미지 외에 대량의 캐릭터 일러스트가 필요한 RPG형 전투
- 보스 일러스트 중심의 콘텐츠를 첫 핵심 모드로 삼는 방향

### 2.2 Pay to Win 금지

아레나의 전투력은 치카포 본편의 경제 가치나 인기도 지표와 연결하지 않는다.

전투력에 사용하면 안 되는 데이터:

- 카드 시세 또는 `base_value`
- 팔로워 수
- 방송 중 여부
- 방송 시간
- 채팅량
- 카드 보유 수량
- 고가 카드 보유 여부
- 치카포 포인트 보유량
- 마켓 구매력

사용 가능한 치카포 데이터:

- 스트리머 이름
- 스트리머 기본 프로필 이미지
- 스트리머 커스텀 카드 이미지
- 별도 카드 이미지 슬롯
- 카드 테두리
- 이름 효과
- 기타 외형 코스메틱

경쟁 모드에서 치카포 본편 자산은 외형, 정체성, 수집 만족감만 제공해야 한다. 승패는 아레나 내부의 덱 구성, 배치, 시너지, 카운터 선택, 전투 규칙 이해도에 의해 결정되어야 한다.

### 2.3 스트리머 권리 보호

스트리머는 자신의 카드가 아레나에 사용되지 않도록 비활성화할 수 있어야 한다.

비활성화 원칙:

- 비활성화된 스트리머 카드는 아레나 카드 풀에서 제외된다.
- 비활성화된 카드는 신규 덱 편성, 랜덤 로스터, 추천 카드, 봇 덱, 이벤트 덱에 등장하지 않는다.
- 이미 편성된 덱에 포함되어 있으면 해당 덱은 자동으로 사용 불가 상태가 되며, 유저에게 교체 안내를 제공한다.
- 리플레이, 과거 전적, 시즌 기록은 무결성을 위해 카드명 대신 비활성 카드 표기 또는 익명 표기 정책을 둔다.
- 스트리머가 재활성화하면 다음 카드 사용 가능 상태 갱신 시점부터 다시 사용 가능하다.

비활성화는 치카포 본편의 카드 삭제나 이미지 차단과 별개로 관리한다. 본편 카드 거래/수집 가능 여부와 아레나 출전 가능 여부는 분리한다.

## 3. 게임 정체성

### 3.1 장르

시즌제 카드 오토배틀러.

유저는 여러 스트리머 카드로 덱과 라운드별 전술 플랜을 구성하고, 전투는 서버가 5판 3선승 세트 매치로 자동 시뮬레이션한다. 클라이언트는 서버 결과를 7~12분 체감의 리플레이 형태로 재생한다.

### 3.2 핵심 재미

- 3,000명에 가까운 스트리머가 각자 다른 컨셉 카드로 등장한다.
- 스트리머는 자신의 카드 콘셉트를 직접 설정할 수 있다.
- 설정하지 않은 스트리머도 기본적으로 고유한 랜덤 템플릿 능력을 가진다.
- 같은 스트리머 카드는 모든 유저에게 항상 같은 능력을 가진다.
- 전투력은 공정한 아레나 규칙 안에서만 결정된다.
- 팬덤은 자기 스트리머 카드의 조합, 카운터, 시너지, 시즌 메타를 연구할 수 있다.

## 4. 카드 능력 생성 구조

### 4.1 카드 구성 요소

각 아레나 카드는 다음 요소로 구성된다.

```text
아레나 카드 =
  표시 정보
  + 역할군
  + 클래스
  + 기본 스탯 프로필
  + 액티브 스킬
  + 패시브 스킬
  + 시너지 태그
  + 밸런스 보정값
  + 출전 상태
```

표시 정보:

- `channel_id`
- 스트리머 이름
- 카드 이미지 URL
- 외형 코스메틱

전투 정보:

- 역할군
- 클래스
- 스탯 프로필
- 액티브 스킬
- 패시브 스킬
- 시너지 태그 2~3개
- 코스트 또는 티어
- 내부 파워 점수

### 4.2 같은 스트리머는 같은 능력

모든 유저가 보는 같은 스트리머 카드는 동일한 능력을 가져야 한다. 유저별 보유 카드, 별 등급, 포인트, 마켓 구매 여부는 능력을 바꾸지 않는다.

기본 능력 생성은 결정적 랜덤 방식을 사용한다.

```text
seed = hash("chikapo-arena:v1:" + channel_id)
```

이 seed로 역할군, 클래스, 스탯 프로필, 액티브 스킬, 패시브 스킬, 시너지 태그를 생성한다. 따라서 스트리머가 직접 설정하기 전에도 카드는 랜덤처럼 다양하지만, 같은 `channel_id`에 대해서는 항상 같은 결과가 나온다.

운영자가 생성 규칙을 바꿀 경우에는 버전을 올린다.

```text
seed = hash("chikapo-arena:v2:" + channel_id)
```

단, 이미 서비스 중인 시즌의 카드 능력은 시즌 도중 임의로 바꾸지 않는다. 변경은 다음 시즌 또는 명시된 밸런스 패치 시점에만 적용한다.

### 4.3 스트리머 직접 설정

스트리머 본인은 자기 아레나 카드의 콘셉트를 설정할 수 있다.

설정 가능 항목:

- 역할군 선호
- 클래스 선택
- 전투 성향 선택
- 액티브 스킬 선택
- 패시브 스킬 선택
- 시너지 태그 일부 선택
- 카드 설명문 또는 플레이버 텍스트

제한:

- 완전 자유 조합은 허용하지 않는다.
- 서버가 검증한 조합 후보 안에서만 선택할 수 있다.
- 선택 가능한 조합은 모두 동일한 파워 예산을 통과해야 한다.
- 시즌 중 변경은 제한하거나 다음 시즌부터 반영한다.
- 금지 조합, 과도한 시너지, 무한 루프 가능 조합은 서버에서 차단한다.

추천 UX:

1. 스트리머가 콘셉트 설문을 진행한다.
2. 서버가 3~5개의 밸런스 통과 프리셋을 추천한다.
3. 스트리머는 그중 하나를 선택한다.
4. 세부 옵션은 제한된 범위에서만 조정한다.
5. 선택 결과는 다음 카드 사용 가능 상태 갱신 또는 다음 시즌부터 반영된다.

### 4.4 미설정 카드의 기본 능력

스트리머가 직접 설정하지 않은 카드는 자동 템플릿 능력을 가진다.

요구사항:

- 모든 등록 스트리머는 아레나 비활성 상태가 아닌 한 기본 능력을 가진다.
- 기본 능력은 랜덤처럼 보이지만 결정적이어야 한다.
- 같은 스트리머 카드는 모든 유저에게 같은 능력이어야 한다.
- 기본 능력도 직접 설정 카드와 같은 파워 예산을 통과해야 한다.
- 기본 능력이라는 이유로 약하거나 강해서는 안 된다.

자동 생성 과정:

1. `channel_id` 기반 seed 생성
2. 역할군 후보 선택
3. 역할군에 맞는 클래스 후보 선택
4. 클래스에 맞는 스탯 프로필 선택
5. 파워 예산에 맞는 액티브/패시브 후보 선택
6. 시너지 태그 선택
7. 금지 조합 검사
8. 파워 점수 허용 범위 검사
9. 생성 결과 저장 또는 캐싱

## 5. 역할군, 클래스, 스탯, 스킬

### 5.1 역할군

초기 역할군은 6종을 권장한다.

- 탱커: 전열 유지, 도발, 보호막
- 브루저: 체력과 공격을 모두 가진 근접 전투형
- 딜러: 단일 대상 처치와 화력 집중
- 캐스터: 광역 피해, 상태 이상, 후열 압박
- 서포터: 회복, 보호, 버프, 해제
- 트릭스터: 위치 교란, 회피, 침묵, 특수 조건 발동

### 5.2 클래스

MVP 클래스는 24종으로 시작한다. 30~50종은 정식 시즌 이후 확장 목표로 둔다.

예시:

- 방패기사
- 결계술사
- 저격수
- 암살자
- 무대지휘자
- 연금술사
- 소환사
- 시간술사
- 폭주전사
- 추격자
- 전술가
- 행운술사
- 방랑검사
- 음유지원가
- 기계공
- 예언자

클래스는 개별 스트리머를 밸런싱하는 단위가 아니라 카드 생성 템플릿의 큰 축이다. 밸런스 패치는 클래스와 스킬 템플릿 단위로 진행한다.

### 5.3 스탯 프로필

스탯은 직접 숫자를 자유롭게 배분하지 않고 프로필 템플릿으로 선택한다.

예시:

- 균형형
- 고체력형
- 고방어형
- 고공속형
- 유리대포형
- 후반성장형
- 초반압박형
- 회피형
- 치명타형
- 에너지 가속형

기본 스탯 후보:

- 체력
- 공격력
- 방어력
- 공격 속도
- 사거리
- 에너지 획득량
- 치명 확률
- 치명 피해
- 상태 이상 저항

### 5.4 스킬

스킬은 수백 개의 개별 하드코딩이 아니라 템플릿과 파라미터로 관리한다.

액티브 스킬 예시:

- 단일 대상 피해
- 광역 피해
- 보호막 부여
- 아군 회복
- 적 침묵
- 적 기절
- 위치 이동
- 도발
- 소환
- 반격 준비
- 에너지 흡수

패시브 스킬 예시:

- 전투 시작 시 보호막
- 체력 50% 이하일 때 회복
- 세 번째 공격마다 추가 피해
- 아군 사망 시 강화
- 적 처치 관여 시 에너지 획득
- 후열에 있을 때 공격력 증가
- 같은 태그 아군 수에 따라 보너스

각 스킬은 다음 메타데이터를 가진다.

```text
skill_id
name
role_tags
allowed_classes
targeting_rule
effect_template
effect_params
cooldown_or_energy_cost
power_cost
counter_tags
forbidden_combo_tags
```

## 6. 밸런스 시스템

### 6.1 파워 예산

모든 카드는 동일한 총 파워 예산 안에서 생성된다.

예시:

```text
총 파워 예산: 100

기본 스탯: 45
액티브 스킬: 30
패시브 스킬: 15
시너지 태그: 10
```

강한 스킬은 높은 `power_cost`를 가진다. 강한 스킬을 선택하면 스탯이나 다른 능력에서 예산이 줄어든다.

### 6.2 금지 조합

다음 조합은 금지한다.

- 무한 회복 루프
- 무한 에너지 루프
- 무한 소환 루프
- 행동 불능을 과도하게 연장하는 조합
- 특정 태그만 모으면 카운터가 불가능해지는 조합
- 전투 시작 즉시 확정 승리를 유도하는 조합

### 6.3 카드 풀 사용 원칙

시즌 로테이션 카드 풀은 사용하지 않는다. 비활성화 카드와 관리자 제한 카드를 제외한 전체 활성 카드를 기본 랭크 대상 카드로 둔다.

원칙:

- 전체 등록 카드: 약 3,000장
- 랭크 사용 가능 카드: `ACTIVE` 상태이며 관리자 제한이 없는 전체 카드
- 주간/시즌 순환 제외 목록은 만들지 않는다.
- 밸런스는 카드 풀 축소가 아니라 파워 예산, 금지 조합, 전술 칩/전장 규칙 통계, 클래스/스킬 패치로 관리한다.
- 신규 유저 학습 부담은 추천 덱, 필터, 튜토리얼, 연습 봇, 전략 프리셋으로 완화한다.
- 비활성화 카드와 관리자 제한 카드는 빠른대전, 8인 컵, 봇 덱, 추천 덱, 관전 하이라이트 신규 노출에서 제외한다.

금지:

- 시즌마다 임의로 일부 카드만 랭크에 열어두는 로테이션 카드 풀
- 특정 스트리머 카드를 메타 조절 목적으로 조용히 제외하는 운영
- 치카포 본편 자산 보유 여부로 사용 가능 카드를 제한하는 구조

## 7. 아레나 모드

### 7.1 랭크 모드

공정성이 최우선인 경쟁 모드다.

원칙:

- 치카포 본편 보유 자산은 전투력에 영향을 주지 않는다.
- 모든 유저는 비활성/관리자 제한을 제외한 같은 전체 활성 카드 목록 안에서 덱을 구성한다.
- 카드 사용 가능 여부는 스트리머 비활성화, 관리자 제한, 시즌 규칙의 금지 상태로만 결정한다.
- 치카포 카드 보유 여부는 외형 스킨, 프로필 장식, 팬 표시 정도로만 반영한다.

### 7.2 친선전

유저가 자유롭게 덱을 실험하는 모드다.

- 전체 활성 카드 사용 가능
- 비활성화 카드 제외
- 밸런스 실험용 비공식 룰 허용 가능
- 보상은 없거나 매우 제한적

### 7.3 커스텀 룸

팬덤, 스트리머, 커뮤니티 이벤트용 모드다.

- 특정 스트리머 그룹만 사용
- 특정 클래스 금지
- 특정 태그 보너스
- 밴픽 없이 전장 규칙과 전술 조건만 적용
- 대회 코드 발급

### 7.4 PvE 확장

초기 핵심 모드는 아니지만, 이후 카드 풀 활용도를 높이기 위해 PvE를 붙일 수 있다.

- 주간 던전
- 연습용 봇전
- 시즌 도전 과제
- 특정 태그 제한 챌린지

PvE에서도 시세, 팔로워, 방송 중 여부를 전투력으로 사용하지 않는다.

### 7.5 8인 아레나 컵

8인 컵은 빠른대전 랭크와 분리된 별도 경쟁 모드다.

- 8명이 컵 큐에 등록한다.
- 컵 전용 덱, 라운드별 전술 플랜, 전술 칩을 제출한다.
- 서버는 컵 전체 결과를 짧은 작업으로 계산한다.
- 유저는 자기 경기, 결승전, 하이라이트 리플레이를 12~25분 체감으로 확인한다.
- 컵 결과는 기본 랭크 MMR에 반영하지 않고 컵 포인트/이벤트 랭킹으로 분리한다.
- 컵은 별도 워커와 kill switch를 가진다.

### 7.6 관전

관전은 완료된 매치와 컵 하이라이트 리플레이 관전으로 시작한다.

- 실시간 tick 브로드캐스트 관전은 제공하지 않는다.
- 관전자별 진행 위치를 서버에 저장하지 않는다.
- 관전은 참가자 공유 링크, 관리자 선정, 대회 코드 등 명확한 권한이 있을 때만 제공한다.
- 스트리머 비활성화 또는 관리자 제한이 적용된 카드는 관전 리플레이에서 비식별/대체 표시를 따른다.
## 8. 스트리머 관리 기능

### 8.1 아레나 카드 설정 페이지

스트리머 본인이 접근 가능한 설정 페이지를 제공한다.

기능:

- 내 아레나 카드 미리보기
- 현재 자동 생성 능력 확인
- 콘셉트 설정 시작
- 추천 프리셋 선택
- 플레이버 텍스트 입력
- 아레나 출전 활성/비활성 설정
- 다음 반영 시점 확인

### 8.2 비활성화 상태

권장 상태값:

```text
ACTIVE: 아레나 사용 가능
OPTED_OUT: 스트리머 요청으로 아레나 사용 불가
ADMIN_DISABLED: 관리자 판단으로 사용 불가
PENDING_REVIEW: 설정 변경 검토 중
```

### 8.3 변경 반영 정책

- 외형 변경: 가능한 빠르게 반영
- 클래스/스킬 변경: 다음 시즌 또는 지정된 밸런스 패치 시점 반영
- 비활성화: 가능한 즉시 반영
- 재활성화: 카드 사용 가능 상태 갱신 시점 반영

## 11. 전투 엔진 방향

서버가 5판 3선승 세트 전투를 시뮬레이션하고, 클라이언트는 결과 로그를 리플레이한다.

장점:

- 치팅 방지
- 결과 재현 가능
- 밸런스 테스트 자동화 용이
- 모바일/저사양 환경에서도 안정적
- 전투 연출을 나중에 개선해도 결과 로직은 유지 가능

전투 로그 예시:

```text
time_ms
actor_card_id
action_type
target_card_ids
effect_id
damage
healing
shield
status_applied
remaining_hp
```

전투 결과는 seed 기반으로 재현 가능해야 한다.

```text
match_seed = hash(season_id + match_id + deck_a_hash + deck_b_hash)
round_seed = hash(match_seed + ":round:" + round_no)
```

- 스트리머 아레나 비활성화

- 1~5라운드 사전 전술 플랜과 라운드별 직접 선택

- 관리자 카드 사용 가능 상태 관리

## 14. 반드시 지켜야 할 결정 사항

이 문서의 후속 기획과 구현은 다음 결정을 어기면 안 된다.

1. 아레나 전투력은 치카포 시세, 팔로워, 방송 중 여부, 채팅량, 포인트, 마켓 구매력과 연결하지 않는다.
2. 치카포 본편 리소스는 이미지와 코스메틱 중심으로 사용한다.
3. 같은 스트리머 카드는 모든 유저에게 같은 능력을 가진다.
4. 스트리머가 설정하지 않은 카드도 결정적 랜덤 템플릿으로 기본 능력을 가진다.
5. 스트리머는 자신의 카드가 아레나에 쓰이지 않도록 비활성화할 수 있다.
6. 3,000장 규모의 고유성은 수작업 개별 밸런싱이 아니라 템플릿 조합과 파워 예산으로 만든다.
7. 경쟁 모드는 공정성을 최우선으로 설계한다.
8. 현재 리소스로 상용 수준을 만들기 위해 카드 중심 오토배틀러 표현을 유지한다.
9. 빠른대전은 5판 3선승 세트 매치를 기본으로 한다.
10. 한 게임의 체감 시간은 7~12분을 목표로 하되, 서버는 매칭 시 덱/시드만 고정하고 각 라운드 커밋 시점에 해당 라운드만 확정한다.
11. 밴픽과 시즌 로테이션 카드 풀은 도입하지 않는다.
12. 8인 컵은 빠른대전과 분리된 별도 모드이며 기본 랭크 MMR과 합치지 않는다.
13. 관전은 완료된 리플레이/하이라이트 기반으로 시작한다.
14. 관리자 통계는 스냅샷/배치 기반으로 제공한다.
