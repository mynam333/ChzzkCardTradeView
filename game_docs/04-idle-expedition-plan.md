# 방치형 원정 게임 기획

## 1. 목표

방치형 원정은 `치카포 프론티어`의 1차 메인 콘텐츠다.

목표는 간단하다.

- 유저가 보유 카드로 파티를 편성한다.
- 파티를 지역에 보낸다.
- 일정 시간이 지나면 결과를 받는다.
- 클래스, 스탯, 패시브, 별 등급, 시세가 결과에 영향을 준다.
- 서버는 유저별 실시간 계산을 하지 않는다.

## 2. 기본 플레이 흐름

1. 유저가 원정 화면에 진입한다.
2. 지역을 선택한다.
3. 원정 시간을 선택한다.
4. 보유 카드 4장으로 파티를 편성한다.
5. 서버가 파티 스냅샷과 seed를 저장한다.
6. 원정 종료 시각 이후 유저가 결과를 수령한다.
7. 서버가 결과를 계산하고 보상을 지급한다.

## 3. 원정 시간

1차 추천 시간:

- 15분: 짧은 접속 루프
- 1시간: 일반 회전 루프
- 4시간: 반나절 루프
- 8시간: 취침/업무 루프

| 시간 | 목적 | 보상 성격 | 유리 클래스 |
| --- | --- | --- | --- |
| 15분 | 자주 접속 | 낮은 재료, 빠른 시즌 점수 | 속공, 타격 |
| 1시간 | 기본 원정 | 표준 재료 | 균형 파티 |
| 4시간 | 장기 원정 | 희귀 재료 기회 | 선봉, 지원, 탐사 |
| 8시간 | 긴 방치 | 안정 보상, 큰 실패 리스크 | 선봉, 지원, 야영/구조 |

## 4. 파티 크기

1차 파티 크기는 4장을 권장한다.

이유:

- 모바일 UI에서 보기 좋다.
- 역할 조합이 생긴다.
- 5장보다 밸런스 계산이 쉽다.
- 3장보다 카드 수집 이유가 강하다.

확장:

- 일부 고난도 지역은 5장 파티 허용
- 일부 빠른 원정은 3장 파티 제한 가능
- 오토리그는 6~8장으로 별도 확장 가능

## 5. 원정 지역

### 5.1 폐방송국

- 콘셉트: 오래된 방송 장비와 오류가 남은 안정형 지역
- 권장 역할군: 선봉, 지원
- 위험: 장기 전투, 누적 피해
- 주요 보상: 기본 재료, 안정 성장 재료
- 특수 이벤트: 장비 고장, 구조 요청, 잔류 신호

성공 보정:

- 선봉 + 지원 조합 시 실패율 감소
- 회복/보호 패시브 보너스
- 딜러만 있는 파티는 장기 원정 보상 감소

### 5.2 알고리즘 숲

- 콘셉트: 추천 알고리즘이 뒤엉킨 미로형 지역
- 권장 역할군: 방해, 전략
- 위험: 무작위 상태이상, 경로 변경
- 주요 보상: 전략 재료, 시즌 조사 점수
- 특수 이벤트: 추천 경로, 숨은 루트, 알고리즘 왜곡

성공 보정:

- 침묵/해제/전략 태그 보너스
- 지도 제작자, 현장 리포터 보너스
- 변수형 패시브는 고점과 저점 모두 가능

### 5.3 시세 폭풍항

- 콘셉트: 카드 시세가 파도처럼 요동치는 항구
- 권장 역할군: 타격, 속공
- 위험: 짧고 강한 전투, 보상 변동
- 주요 보상: 공격 재료, 거래형 재료
- 특수 이벤트: 급등 파도, 급락 소용돌이, 상인 조우

성공 보정:

- 빠른 전투 완료 시 추가 점수
- 보스/정예 처리 클래스 유리
- 고시세 카드는 성능 보정이 있지만 코스트 상승

### 5.4 팬덤 광장

- 콘셉트: 응원과 이벤트가 열리는 커뮤니티형 지역
- 권장 역할군: 지원, 탐사
- 위험: 전투보다 선택 이벤트 중심
- 주요 보상: 시즌 점수, 꾸미기 재료, 칭호 재료
- 특수 이벤트: 응원전, 부스 지원, 팬미팅 준비

성공 보정:

- 공명 스탯 보너스
- 지원/탐사 역할군 보너스
- 다양한 역할군 파티에 추가 보정

### 5.5 심야 송출탑

- 콘셉트: 밤마다 강해지는 고난도 탑
- 권장 역할군: 술식, 방해
- 위험: 강한 보스 이벤트, 상태이상, 실패 리스크
- 주요 보상: 희귀 재료, 고급 성장 재료
- 특수 이벤트: 심야 패턴, 송출 왜곡, 보스 난입

성공 보정:

- 장기전/방해/술식 태그 유리
- 정화 없으면 실패율 증가
- 고위험 패시브 고점 허용

## 6. 결과 계산 구조

결과는 크게 4개 점수로 계산한다.

### 6.1 전투 점수

전투 성공 가능성을 나타낸다.

영향 요소:

- 공격, 방어, 체력
- 타격/선봉 역할군
- 지역 적합도
- 별 등급
- 시세 보정
- 전투형 패시브

### 6.2 안정 점수

실패율과 사고 이벤트 피해를 줄인다.

영향 요소:

- 체력, 방어, 공명
- 선봉/지원 역할군
- 회복/보호/정화 패시브
- 장시간 원정 보정

### 6.3 탐사 점수

보상 슬롯, 특수 이벤트, 시즌 조사 점수에 영향을 준다.

영향 요소:

- 속도, 기교, 공명
- 탐사/전략 역할군
- 보상/시간/시즌 패시브
- 지역별 특화 클래스

### 6.4 변수 점수

무작위 고점과 저점을 만든다.

영향 요소:

- 기교
- 술식/변수 패시브
- 위험형 패시브
- 지역 이벤트 seed

## 7. 성공률 설계

원정은 완전 성공/부분 성공/실패로 나눈다.

- 대성공: 기본 보상 + 추가 슬롯 + 시즌 점수 보너스
- 성공: 기본 보상
- 부분 성공: 기본 보상 일부
- 실패: 낮은 보상 또는 안전 귀환 효과만 적용

권장 초기 확률:

- 적정 파티 성공률: 70~85%
- 권장 역할 충족 시: 80~92%
- 부적합 파티: 45~65%
- 고난도 지역: 35~75%

실패가 너무 많으면 방치형 피로감이 커진다. 실패해도 일부 보상은 주는 편이 좋다.

## 8. 보상 설계

### 8.1 보상 종류

- 기본 재료
- 역할군 재료
- 지역 재료
- 시즌 조사 점수
- 장비 파편
- 꾸미기 재료
- 낮은 확률의 희귀 재료

### 8.2 포인트 보상

포인트는 기존 경제와 연결되어 있어 조심해야 한다.

권장:

- 기본 원정 보상으로 대량 포인트 금지
- 이벤트/업적/시즌 정산으로 제한적 지급
- 포인트 대신 프론티어 전용 재화 사용

### 8.3 보상형 패시브 상한

보상형 패시브는 아래 상한을 둔다.

- 추가 보상 슬롯: 파티당 최대 1개
- 시간 단축: 총합 최대 10~15%
- 희귀 재료 확률 증가: 곱연산 금지, 합연산 상한
- 실패 보상 보존: 최대 50% 이하

## 9. 서버 정산 방식

### 9.1 원정 시작

서버 저장값:

- `expedition_id`
- `user_id`
- `region_id`
- `duration_minutes`
- `started_at`
- `finishes_at`
- `party_snapshot_json`
- `seed`
- `status`: started

`party_snapshot_json`에는 시작 당시 카드의 클래스, 스탯, 패시브, 별 등급, 시세 구간, 코스트를 복사한다.

### 9.2 원정 진행 중

서버는 아무 계산도 하지 않는다.

필요한 조회:

- 남은 시간
- 파티 정보
- 취소 가능 여부

### 9.3 결과 수령

`finishes_at` 이후 유저가 결과 수령 API를 호출한다.

서버는:

1. 원정 소유권 확인
2. 상태 확인
3. seed와 snapshot으로 결과 계산
4. 보상 지급
5. 상태 completed로 변경
6. 결과 로그 저장

결과 수령은 멱등 처리해야 한다. 같은 원정에서 보상이 2회 지급되면 안 된다.

## 10. 원정 취소

원정 취소는 단순하게 시작한다.

권장:

- 시작 후 1분 이내 무료 취소
- 이후 취소 시 보상 없음
- 이미 완료 가능한 원정은 취소 불가

취소 보상을 넣으면 어뷰징 경로가 늘어난다.

## 11. 자동 편성

유저 편의를 위해 자동 편성을 제공한다.

모드:

- 안정형: 선봉/지원 우선
- 빠른 원정형: 속공/타격 우선
- 보상형: 탐사/전략 우선
- 보스형: 단일 딜/표식/지원 우선
- 균형형: 역할군 다양성 우선

자동 편성은 최적해가 아니라 입문용이어야 한다. 고급 유저가 직접 조합할 여지는 남긴다.

## 12. 원정 결과 화면

결과 화면에 보여줄 것:

- 파티 카드 4장
- 성공/대성공/부분 성공/실패
- 획득 보상
- 클래스별 기여
- 발동한 패시브
- 지역 이벤트
- 다음 추천 원정

기여 표시는 딜량만 보여주면 안 된다.

기여 항목:

- 피해
- 보호
- 회복
- 방해
- 탐사
- 보상 발견
- 시간 단축

## 13. 1차 출시 지역 난도

초기 난도:

- 폐방송국: 쉬움
- 팬덤 광장: 쉬움
- 시세 폭풍항: 보통
- 알고리즘 숲: 보통
- 심야 송출탑: 어려움

각 지역은 쉬움/보통/어려움 난도를 나중에 확장한다.

## 14. 확장 후보

- 원정 중 돌발 선택지
- 파티 리더 스킬
- 지역별 일일 변동 버프
- 시즌 지역 개방
- 희귀 보스 난입
- 친구 지원 카드 대여
- 특정 클래스 주간 보너스
