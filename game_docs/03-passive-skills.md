# 패시브 스킬 종류와 효과

## 1. 패시브 스킬 목표

패시브 스킬은 같은 클래스 안에서도 스트리머 카드의 개성을 나누는 장치다.

스트리머는 패시브 2개를 선택한다. 패시브 선택은 자유로워야 한다. 특정 조합을 금지하지 않고, 게임 밸런스와 경제 보상이 무너지지 않도록 효과 축별 점감과 상한을 둔다.

## 2. 패시브 선택 규칙

- 스트리머는 패시브 2개를 선택한다.
- 클래스마다 허용 태그가 있다.
- 패시브는 허용 태그 중 하나 이상과 일치해야 선택 가능하다.
- 같은 효과 축의 패시브를 함께 선택할 수 있지만, 중첩 효율은 점감한다.
- `탐사형` 패시브를 여러 개 선택할 수 있지만, 보상/시간/희귀 발견 효과는 합산 상한을 가진다.
- `변수형` 패시브를 여러 개 선택할 수 있지만, 추가 행동/확률 고점 효과는 점감한다.
- 보상 기대값을 직접 올리는 패시브를 함께 선택할 경우 두 번째 효과부터 점감한다.
- 클래스의 약점을 완화할 수는 있지만, 약점 축을 완전히 제거하지 않도록 상한을 둔다.

## 4. 위험도

### 4.1 낮음

- 단순 능력치 소폭 증가
- 특정 상황에서 작은 보정
- 대부분 자유 선택 가능

### 4.2 중간

- 전투 결과에 큰 영향을 줄 수 있음
- 점감/상한 필요
- 시즌 통계 모니터링 필요

### 4.3 높음

- 추가 행동, 복사, 보상 증가, 시간 단축, 큰 확률 효과
- 중복 시 점감
- 특정 클래스만 선택 가능
- 시즌 중 비활성화 가능해야 함

## 5. 1차 출시 추천 패시브 48종

### 5.1 방어/보호

#### 굳건한 첫인상

- 태그: 방어, 보호, 안정
- 위험도: 낮음
- 효과: 전투 시작 시 자신에게 최대 체력 비례 보호막을 얻는다.
- 원정 영향: 전투형 원정의 초기 피해 감소
- 레이드 영향: 첫 광역 패턴 완화
- 밸런스 처리: `방송 사고 대처`와 동시 선택 시 보호막 수치 감소

#### 마지막 방패

- 태그: 보호, 지원, 안정
- 위험도: 중간
- 효과: 아군이 치명 피해를 받을 때 전투당 1회 피해 일부를 감소시킨다.
- 원정 영향: 실패 직전 생존 가능성 증가
- 레이드 영향: 큰 패턴 대응
- 밸런스 처리: 강력 생존 패시브와 중복 시 점감

#### 관객 보호 본능

- 태그: 보호, 지원
- 위험도: 낮음
- 효과: 가장 체력이 낮은 아군이 받는 피해를 소폭 줄인다.
- 원정 영향: 안정성 증가
- 레이드 영향: 후열 보호
- 밸런스 처리: 없음

#### 느긋한 호흡

- 태그: 방어, 장기전
- 위험도: 낮음
- 효과: 전투가 길어질수록 방어가 조금씩 증가한다.
- 원정 영향: 긴 전투 지역에 유리
- 레이드 영향: 장기전 생존
- 밸런스 처리: 없음

#### 단단한 멘탈

- 태그: 방어, 정화, 안정
- 위험도: 낮음
- 효과: 상태이상 저항이 증가한다.
- 원정 영향: 특수 사고 이벤트 대응
- 레이드 영향: 디버프 보스 대응
- 밸런스 처리: 없음

#### 방송 사고 대처

- 태그: 방어, 보호, 안정
- 위험도: 중간
- 효과: 전투당 1회 큰 피해를 작은 피해로 완화한다.
- 원정 영향: 사고 이벤트 피해 감소
- 레이드 영향: 보스 큰 패턴 완화
- 밸런스 처리: `마지막 방패`와 동시 발동 시 보호 효과 점감

- 원정 영향: 위험 지역 고점
- 레이드 영향: 힐러 조합과 시너지
- 밸런스 처리: `위험한 몰입`과 함께 쓰면 위험 축 점감과 생존 부담 증가

#### 기억 재생

- 태그: 술식, 전략, 장기전
- 위험도: 중간
- 효과: 이전 전투에서 가장 많이 쓴 역할군을 강화한다.
- 원정 영향: 반복 원정 파티 강화
- 레이드 영향: 장기전 누적 보정
- 밸런스 처리: 없음

#### 무작위 편성표

- 태그: 술식, 변수
- 위험도: 중간
- 효과: 전투 시작 시 랜덤 스탯 1개가 증가한다.
- 원정 영향: 랜덤 보정
- 레이드 영향: 상황별 편차
- 밸런스 처리: 변수형 효과 점감 적용

### 5.7 전략/연계

#### 역할 분담

- 태그: 전략, 연계, 지원
- 위험도: 낮음
- 효과: 파티 역할군이 4종 이상이면 전체 능력치가 증가한다.
- 원정 영향: 균형 파티 보상
- 레이드 영향: 역할 분산 파티 강화
- 밸런스 처리: 없음

#### 같은 결 다른 맛

- 태그: 전략, 연계
- 위험도: 낮음
- 효과: 같은 역할군 2명 편성 시 해당 역할군 효과가 증가한다.
- 원정 영향: 역할 특화 파티 강화
- 레이드 영향: 주력 역할 축을 보강하되 부족 축은 별도 보완 필요

- 밸런스 처리: 행동 게이지 증가 상한 필요

- 밸런스 처리: 버프 증폭 상한 필요

## 6. 시즌 확장 패시브 후보 16종

- `역전의 버팀목`: 체력이 낮을수록 받는 회복량 증가
- `뒤끝 없는 반격`: 방어 성공 후 낮은 피해로 반격
- `정확한 썸네일`: 빗나감/회피당할 확률 감소
- `가벼운 발걸음`: 원정 시간 소폭 감소
- `틈새 공략`: 적이 행동한 직후 공격하면 피해 증가
- `과치유 저장`: 초과 회복 일부를 보호막으로 전환
- `무리하지 마세요`: 체력이 낮은 아군에게 받는 피해 감소 부여
- `분위기 전환`: 적이 버프를 받으면 낮은 확률로 약화 부여
- `집중 저격`: 같은 디버프가 2개 이상인 적에게 피해 증가
- `분신 잔상`: 소환/복사 효과 지속시간 증가
- `예고편 공개`: 다음 아군 행동을 강화하되 적에게도 작은 게이지 부여
- `복선 회수`: 조건부 효과 성공 시 추가 보상 점수
- `백업 플랜`: 원정 실패 시 재도전 비용 감소
- `짧은 원정 전문가`: 1시간 이하 원정 보상 효율 증가
- `마켓 감각`: 원정 재료 판매형 보상 획득량 소폭 증가
- `무대 뒤 지원`: 파티 첫 슬롯이 아니면 지원 효과 증가

## 7. 점감 처리 예시

특정 조합을 금지하지 않는다. 대신 같은 효과 축이 겹치면 효율이 낮아지거나 보조 효과로 전환된다.

- `숨은 보급품` + `희귀 냄새`: 희귀 보상 확률은 상한을 적용하고, 초과분은 정보 힌트로 전환한다.
- `빠른 루트` + `가벼운 발걸음`: 시간 단축 총량은 상한을 적용하고, 초과분은 다음 위험 단계 예고로 전환한다.
- `행운의 컷` + 추가 행동 클래스 강화 패시브: 추가 행동 게이지 획득량을 점감한다.
- `마지막 방패` + `방송 사고 대처`: 피해 완화 총량 상한을 적용한다.
- `위험한 몰입` + `그림자 거래`: 공격 고점은 유지하되 생존 부담도 함께 커진다.
- `복선 회수` + 보상 증가 패시브: 보상 증가는 상한을 적용하고, 초과분은 시즌 조사 점수로 낮은 비율 전환한다.
- `보물 탐색가` 클래스 + 보상형 패시브 2개: 추가 보상은 점감하고, 탐사 로그/힌트 품질이 오른다.
- `복제 연출가` 클래스 + 복사/추가행동 패시브 2개: 복사 효과 계수와 추가 행동 게이지를 점감한다.

- 오토리그 승률
- 특정 클래스와의 조합 편중
- 상위 유저의 패시브 고착률
- 시즌별 점감/상한 조정 필요 후보
