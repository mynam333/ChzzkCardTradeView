# 패시브 스킬 종류와 효과

## 1. 패시브 스킬 목표

패시브 스킬은 같은 클래스 안에서도 스트리머 카드의 개성을 나누는 장치다.

스트리머는 패시브 2개를 선택한다. 패시브 선택은 자유로워야 하지만, 게임 밸런스와 경제 보상을 무너뜨릴 수 있으므로 태그와 조합 제한을 둔다.

## 2. 패시브 선택 규칙

- 스트리머는 패시브 2개를 선택한다.
- 클래스마다 허용 태그가 있다.
- 패시브는 허용 태그 중 하나 이상과 일치해야 선택 가능하다.
- 같은 `exclusive_group`의 패시브는 동시에 선택할 수 없다.
- `탐사형` 패시브는 최대 1개만 선택 가능하다.
- `변수형` 패시브는 최대 1개만 선택 가능하다.
- 보상 기대값을 직접 올리는 패시브 2개 동시 선택은 금지한다.
- 클래스의 약점을 완전히 없애는 조합은 금지한다.

## 4. 위험도

### 4.1 낮음

- 단순 능력치 소폭 증가
- 특정 상황에서 작은 보정
- 대부분 자유 선택 가능

### 4.2 중간

- 전투 결과에 큰 영향을 줄 수 있음
- 조합 제한 필요
- 시즌 통계 모니터링 필요

### 4.3 높음

- 추가 행동, 복사, 보상 증가, 시간 단축, 큰 확률 효과
- 중복 선택 금지
- 특정 클래스만 선택 가능
- 시즌 중 비활성화 가능해야 함

## 5. 1차 출시 추천 패시브 48종

### 5.1 방어/보호

#### 굳건한 첫인상

- 태그: 방어, 보호, 안정
- 위험도: 낮음
- 효과: 전투 시작 시 자신에게 최대 체력 비례 보호막을 얻는다.
- 원정 영향: 전투형 원정의 초기 피해 감소
- 레이드 영향: 첫 광역 패턴 완화
- 조합 제한: `방송 사고 대처`와 동시 선택 시 보호막 수치 감소

#### 마지막 방패

- 태그: 보호, 지원, 안정
- 위험도: 중간
- 효과: 아군이 치명 피해를 받을 때 전투당 1회 피해 일부를 감소시킨다.
- 원정 영향: 실패 직전 생존 가능성 증가
- 레이드 영향: 큰 패턴 대응
- 조합 제한: 강력 생존 패시브와 중복 제한

#### 관객 보호 본능

- 태그: 보호, 지원
- 위험도: 낮음
- 효과: 가장 체력이 낮은 아군이 받는 피해를 소폭 줄인다.
- 원정 영향: 안정성 증가
- 레이드 영향: 후열 보호
- 조합 제한: 없음

#### 느긋한 호흡

- 태그: 방어, 장기전
- 위험도: 낮음
- 효과: 전투가 길어질수록 방어가 조금씩 증가한다.
- 원정 영향: 긴 전투 지역에 유리
- 레이드 영향: 장기전 생존
- 조합 제한: 없음

#### 단단한 멘탈

- 태그: 방어, 정화, 안정
- 위험도: 낮음
- 효과: 상태이상 저항이 증가한다.
- 원정 영향: 특수 사고 이벤트 대응
- 레이드 영향: 디버프 보스 대응
- 조합 제한: 없음

#### 방송 사고 대처

- 태그: 방어, 보호, 안정
- 위험도: 중간
- 효과: 전투당 1회 큰 피해를 작은 피해로 완화한다.
- 원정 영향: 사고 이벤트 피해 감소
- 레이드 영향: 보스 큰 패턴 완화
- 조합 제한: `마지막 방패`와 동시 선택 시 둘 중 하나만 발동

- 태그: 술식, 변수
- 위험도: 중간
- 효과: 전투 시작 시 랜덤 스탯 1개가 증가한다.
- 원정 영향: 랜덤 보정
- 레이드 영향: 상황별 편차
- 조합 제한: 변수형 1개 제한 적용

### 5.7 전략/연계

#### 역할 분담

- 태그: 전략, 연계, 지원
- 위험도: 낮음
- 효과: 파티 역할군이 4종 이상이면 전체 능력치가 증가한다.
- 원정 영향: 균형 파티 보상
- 레이드 영향: 역할 분산 파티 강화
- 조합 제한: 없음

#### 같은 결 다른 맛

- 태그: 전략, 연계
- 위험도: 낮음
- 효과: 같은 역할군 2명 편성 시 해당 역할군 효과가 증가한다.
- 원정 영향: 역할 특화 파티 강화
- 레이드 영향: 특정 역할 몰아주기
- 조합 제한: 없음

#### 교대 타이밍

- 태그: 전략, 보호, 속공
- 위험도: 중간
- 효과: 아군이 큰 피해를 받으면 다음 아군 행동 게이지가 증가한다.
- 원정 영향: 위기 대응
- 레이드 영향: 큰 패턴 후 반격
- 조합 제한: 행동 게이지 증가 상한 필요

#### 시너지 큐시트

- 태그: 전략, 버프, 연계
- 위험도: 중간
- 효과: 인접한 파티 슬롯의 버프 효과가 증가한다.
- 원정 영향: 배치 고민 증가
- 레이드 영향: 버프 파티 강화
- 조합 제한: 버프 증폭 상한 필요

#### 작전명 고정

- 태그: 전략, 원정, 안정
- 위험도: 중간
- 효과: 같은 파티로 반복 원정 시 성공률이 증가한다. 일일 상한이 있다.
- 원정 영향: 반복 플레이 보상
- 레이드 영향: 없음
- 조합 제한: 일일 상한 필수

#### 리더의 콜

- 태그: 전략, 지원
- 위험도: 낮음
- 효과: 자신이 파티 첫 슬롯이면 지원 효과가 증가한다.
- 원정 영향: 리더 슬롯 의미 부여
- 레이드 영향: 지원 리더 강화
- 조합 제한: 없음

### 5.8 탐사/보상

- 태그: 탐사, 보상
- 위험도: 높음

- 원정 영향: 기대 보상 증가
- 레이드 영향: 없음
- 조합 제한: 보상형 패시브 중복 금지

#### 빠른 루트

- 효과: 원정 시간이 감소한다.
- 원정 영향: 회전율 증가

- 조합 제한: 시간 단축 패시브 중복 금지

- 효과: 시즌 조사 점수가 증가한다.

- 레이드 영향: 시즌 이벤트 보정
- 조합 제한: 보상형 패시브와 중복 제한 후보

#### 안전 귀환

- 위험도: 중간
- 효과: 실패 시 보상 일부를 보존한다.

- 레이드 영향: 없음
- 조합 제한: 강력 안정 패시브와 중복 제한

- 효과: 4시간 이상 원정 성공률이 증가한다.

- 레이드 영향: 없음

## 6. 시즌 확장 패시브 후보 16종

- `역전의 버팀목`: 체력이 낮을수록 받는 회복량 증가
- `뒤끝 없는 반격`: 방어 성공 후 낮은 피해로 반격
- `정확한 썸네일`: 빗나감/회피당할 확률 감소
- `가벼운 발걸음`: 원정 시간 소폭 감소
- `틈새 공략`: 적이 행동한 직후 공격하면 피해 증가
- `과치유 저장`: 초과 회복 일부를 보호막으로 전환
- `무리하지 마세요`: 체력이 낮은 아군에게 받는 피해 감소 부여
- `분위기 전환`: 적이 버프를 받으면 낮은 확률로 약화 부여
- `집중 저격`: 같은 디버프가 2개 이상인 적에게 피해 증가
- `분신 잔상`: 소환/복사 효과 지속시간 증가
- `예고편 공개`: 다음 아군 행동을 강화하되 적에게도 작은 게이지 부여
- `복선 회수`: 조건부 효과 성공 시 추가 보상 점수
- `백업 플랜`: 원정 실패 시 재도전 비용 감소
- `짧은 원정 전문가`: 1시간 이하 원정 보상 효율 증가
- `마켓 감각`: 원정 재료 판매형 보상 획득량 소폭 증가
- `무대 뒤 지원`: 파티 첫 슬롯이 아니면 지원 효과 증가
