# 밸런스와 클래스 분산 정책

## 1. 목표

스트리머가 자유롭게 클래스를 선택하게 하면 특정 인기 클래스, 특히 딜러 계열에 선택이 몰릴 가능성이 높다.

이 문서는 선택 자유를 유지하면서도 클래스 분포를 자연스럽게 넓히는 운영 장치를 정의한다.

## 2. 기본 원칙

- 강제 배정은 피한다.
- 부족 클래스는 보상과 노출로 유도한다.
- 전투력 보너스는 작게 준다.
- 보상형 보너스는 상한을 둔다.
- 역할별 활약 지표를 따로 보여준다.
- 유저 수요가 다양해지도록 콘텐츠를 설계한다.

## 3. 클래스 쏠림 원인

예상 쏠림:

- 딜러가 직관적으로 강해 보인다.
- 보스 딜 랭킹이 있으면 타격 계열이 유리하다.
- 탐사/지원 클래스는 체감이 약할 수 있다.
- 스트리머는 자기 카드가 강하게 보이길 원한다.
- 유저는 고시세/고성 카드 중심으로 편성하려 한다.

대응은 “딜러 너프”가 아니라 “역할별 보상 경험”을 만드는 것이다.

## 4. 희소 클래스 보너스

시즌마다 클래스 선택 비율을 집계한다.

예:

- 전체 선택률 8% 이상: 과밀
- 4~8%: 적정
- 2~4%: 부족
- 2% 미만: 희소

보너스:

- 부족 클래스: 시즌 점수 +2%
- 희소 클래스: 시즌 점수 +3%, 클래스 도감 강조
- 과밀 클래스: 보너스 없음

주의:

- 전투력 직접 보너스는 최대 +1~2% 수준으로 제한
- 보상 기대값을 크게 올리면 메타가 급변한다
- 보너스는 시즌 단위로 고정해 예측 가능하게 한다

## 5. 추천 클래스 시스템

스트리머가 빌드를 처음 설정할 때 추천 클래스 3개를 보여준다.

추천 기준:

- 현재 부족한 역할군
- 해당 스트리머 카드의 시세/활동 지표
- 스트리머가 가진 카드 이미지 분위기
- 유저 파티에서 많이 비는 역할
- 시즌 지역/보스에서 필요한 역할

추천 UI:

- `현재 부족한 역할`
- `이번 시즌 추천`
- `입문자에게 쉬움`
- `고급 조합용`

추천은 강제하지 않는다. 다만 추천 클래스를 선택하면 작은 비경제 보상을 준다.

예:

- 스트리머 프로필 배지
- 클래스 설정 화면 특별 테두리
- 시즌 소개 페이지 노출

## 6. 클래스별 시즌 미션

역할별로 다른 기여 미션을 둔다.

| 역할군 | 시즌 미션 |
| --- | --- |
| 선봉 | 누적 보호량, 피해 흡수 |
| 타격 | 보스 피해, 정예 처치 |
| 속공 | 원정 시간 단축, 선제 행동 |
| 지원 | 회복량, 보호막량 |
| 방해 | 디버프 성공, 패턴 지연 |
| 술식 | 조건 발동, 누적 폭발 |
| 전략 | 시너지 발동, 조건 성공 |
| 탐사 | 추가 보상 발견, 시즌 조사 점수 |

전체 랭킹 하나만 두면 딜러가 유리하다. 역할군별 랭킹과 보상을 나눠야 한다.

## 7. 유저 수요 분산 장치

스트리머가 다양한 클래스를 고르게 하려면 유저가 다양한 클래스를 원해야 한다.

### 7.1 지역별 역할 요구

각 원정 지역은 유리한 역할군이 다르다.

- 폐방송국: 선봉/지원
- 알고리즘 숲: 방해/전략
- 시세 폭풍항: 타격/속공
- 팬덤 광장: 지원/탐사
- 심야 송출탑: 술식/방해

### 7.2 도감 보너스

유저가 다양한 클래스 카드를 모으면 작은 계정 보너스를 받는다.

예:

- 역할군 8종 보유: 원정 재료 +1%
- 클래스 10종 보유: 시즌 점수 +1%
- 클래스 20종 보유: 프론티어 도감 배지
- 클래스 30종 보유: 특별 칭호

전투력 보너스는 작게 유지한다.

### 7.3 파티 시너지

다양한 역할군을 넣으면 안정성이 오르고, 같은 역할군을 2장 넣으면 특화 효과를 준다.

예:

- 역할군 4종: 전체 안정 점수 증가
- 선봉 2장: 피해 감소 증가, 딜 감소
- 타격 2장: 피해 증가, 실패율 증가
- 지원 2장: 생존 증가, 원정 시간 증가
- 탐사 2장: 보상 증가, 전투 점수 감소

## 8. 파티 코스트

파티 코스트는 고성/고시세 카드만 넣는 문제를 줄인다.

코스트 요소:

- 별 등급
- 시세 구간
- 클래스 희소도
- 패시브 위험도
- 시즌 보정

권장:

- 원정 기본 코스트 제한은 느슨하게
- 오토리그 코스트 제한은 엄격하게
- 레이드에는 고코스트 카드 사용 가능하되 일일 횟수/소모값으로 조절

## 9. 시세 밸런스

시세는 치카포의 정체성이지만 전투력을 지배하면 안 된다.

권장 구조:

- 고시세 카드: 능력 +3%, 코스트 증가
- 중시세 카드: 기준값
- 저시세 카드: 성장/탐사 보너스 +3%

시세 보정은 시즌 시작 시 스냅샷하거나, 하루 1회만 반영한다. 실시간 시세 변동이 전투력을 즉시 바꾸면 유저 경험이 불안정해진다.

## 10. 별 등급 밸런스

별 등급은 유의미해야 하지만 저성 카드도 쓸 수 있어야 한다.

권장:

- 별 등급은 계수 증가와 연출 중심
- 특정 기능을 고성에만 잠그지 않는다
- 5성 카드는 강하지만 코스트도 높다
- 저성 카드는 탐사/도감/코스트 효율로 쓰임새를 준다

## 11. 보상형 클래스 제한

탐사/보상 계열은 반드시 상한이 필요하다.

상한:

- 파티 내 보상형 클래스 효과는 2개까지만 주요 효과 적용
- 추가 보상 슬롯은 원정당 최대 1개
- 희귀 보상 확률은 총합 상한 적용
- 시간 단축은 총합 10~15% 상한
- 실패 보상 보존은 최대 50% 이하

## 12. 오토리그 밸런스

오토리그는 가장 밸런스가 민감하다.

출시 전 필수:

- 파티 코스트
- 전투 로그
- 클래스별 승률 통계
- 패시브별 승률 통계
- 시즌 밴/제한 기능
- 방어 파티와 공격 파티 구분

오토리그에서는 탐사/보상 패시브의 전투 효과를 낮게 두거나 별도 효과로 변환한다.

## 13. 밸런스 지표

관리자는 아래 지표를 봐야 한다.

- 클래스 선택률
- 역할군 선택률
- 패시브 선택률
- 클래스별 원정 성공률
- 클래스별 평균 보상 기대값
- 클래스별 레이드 기여도
- 클래스별 오토리그 승률
- 상위 5% 유저의 편성 고착도
- 지역별 추천 역할 충족률
- 시세 구간별 사용률
- 별 등급별 사용률

## 14. 조정 정책

너프보다 먼저 콘텐츠 보정을 사용한다.

우선순위:

1. 특정 지역/보스에서 다른 역할군을 유리하게 만든다.
2. 희소 클래스 보너스를 조정한다.
3. 파티 코스트를 조정한다.
4. 패시브 상한을 조정한다.
5. 클래스 계수를 조정한다.
6. 심각한 경우 시즌 중 임시 비활성화한다.

시즌 중 대규모 너프는 신뢰를 해친다. 가능하면 시즌 종료 시 반영한다.

## 15. 스트리머 변경 정책

스트리머 클래스 변경은 자유롭되 남용은 막는다.

권장:

- 시즌 시작 전 자유 변경
- 시즌 중 무료 변경 1회
- 이후 변경은 쿨다운 또는 프론티어 재화 필요
- 과밀 클래스 변경은 다음 시즌부터 적용 가능
- 부족 클래스 변경은 즉시 적용 가능

진행 중인 원정/전투는 시작 시점 스냅샷을 사용하므로 변경 영향을 받지 않는다.

## 16. 커뮤니케이션 원칙

밸런스 정책은 유저와 스트리머에게 이해 가능해야 한다.

좋은 표현:

- “부족한 역할군이라 이번 시즌 보너스가 있습니다.”
- “이 클래스는 전투보다 탐사 보상에 강합니다.”
- “고시세 카드는 강하지만 파티 코스트가 높습니다.”
- “보상형 패시브는 파티당 주요 효과가 제한됩니다.”

피해야 할 표현:

- “인기 클래스라 페널티를 줍니다.”
- “강해서 너프했습니다.”
- “시스템상 불가능합니다.”
