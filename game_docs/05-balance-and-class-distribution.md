# 밸런스와 클래스 분산 정책

## 1. 목표

스트리머가 자유롭게 클래스를 선택하게 하면 특정 인기 클래스, 특히 직접 피해 계열에 선택이 몰릴 가능성이 높다.

이 문서는 선택 자유를 유지하면서도 모든 역할군이 전체 콘텐츠에서 계속 필요하도록 만드는 운영 장치를 정의한다.

중요한 전제:

- 특정 지역이 특정 역할군만 요구하는 구조는 피한다.
- 특정 조합을 금지하지 않는다.
- 시세는 프론티어 성능, 보상, 코스트에 영향을 주지 않는다.
- 밸런스는 금지/차단보다 점감, 역할별 기여 분리, 콘텐츠별 복합 요구치로 맞춘다.

## 2. 기본 원칙

- 강제 배정은 피한다.
- 모든 지역은 모든 역할군의 기여처를 가진다.
- 지역마다 “필수 역할”이 아니라 “상황 비중”만 다르게 둔다.
- 특정 조합을 막지 않고, 과도한 중첩은 점감한다.
- 전투력 보너스는 카드의 클래스, 능력치, 패시브, 별 등급 중심으로 계산한다.
- 시세는 프론티어 계산에서 제외한다.
- 역할별 활약 지표를 따로 보여준다.
- 유저 수요가 다양해지도록 파티 목표를 다층화한다.

## 3. 클래스 쏠림 원인

예상 쏠림:

- 딜러가 직관적으로 강해 보인다.
- 보스 딜 랭킹이 있으면 타격 계열이 유리하다.
- 탐사/지원 클래스는 체감이 약할 수 있다.
- 스트리머는 자기 카드가 강하게 보이길 원한다.
- 유저는 고성 카드나 유명 스트리머 카드 중심으로 편성하려 한다.

대응은 “딜러 너프”가 아니라 “모든 역할군의 기여를 보이게 하고, 모든 지역에서 다층 목표를 제공하는 것”이다.

## 4. 전 지역 복합 역할 구조

모든 원정 지역은 아래 5개 판정 축을 가진다.

| 판정 축 | 주요 역할 | 설명 |
| --- | --- | --- |
| 전투 돌파 | 타격, 속공, 술식 | 적을 빠르게 처리하고 정예/보스 단계를 넘긴다. |
| 생존 유지 | 선봉, 지원 | 피해, 피로도, 장기 원정 위험을 줄인다. |
| 상태 대응 | 방해, 지원, 전략 | 상태이상, 강화 적, 특수 패턴을 제어한다. |
| 탐사/보상 | 탐사, 전략, 속공 | 숨은 보상, 경로 단축, 이벤트 성공률에 기여한다. |
| 변수/고점 | 술식, 전략, 방해 | 조건부 고점, 돌발 선택, 어려운 단계 우회에 기여한다. |

지역마다 이 축들의 비중만 다르다. 어떤 지역도 하나의 역할군만 정답이 되어서는 안 된다.

예:

- 폐방송국: 생존 유지 비중이 높지만, 전투 돌파와 상태 대응도 필요하다.
- 알고리즘 숲: 상태 대응과 변수/고점 비중이 높지만, 생존과 탐사도 필요하다.
- 폭풍항: 전투 돌파와 속도 비중이 높지만, 탐사와 생존이 보상 안정성을 만든다.
- 팬덤 광장: 탐사/보상과 지원 비중이 높지만, 전투와 전략 선택도 필요하다.
- 심야 송출탑: 모든 축이 높은 고난도 종합 검정 지역이다.

## 5. 지역 설계 원칙

기존의 `지역별 유리 역할군` 표현은 `지역별 판정 비중`으로 바꾼다.

나쁜 구조:

- “이 지역은 방해/전략 지역이다.”
- “지원이 없는 파티는 이 지역을 못 돈다.”
- “탐사 캐릭터는 특정 지역이 끝나면 쓸 곳이 없다.”

좋은 구조:

- “이 지역은 상태 대응 판정이 자주 나오지만, 전투/생존/탐사 판정도 함께 나온다.”
- “지원이 있으면 안정도가 오르지만, 다른 조합도 접속 개입이나 패시브로 돌파 가능하다.”
- “탐사 역할은 모든 지역에서 보상/경로/정보 판정에 참여한다.”

## 6. 희소 클래스 보너스

시즌마다 클래스 선택 비율을 집계한다.

예:

- 전체 선택률 8% 이상: 과밀
- 4~8%: 적정
- 2~4%: 부족
- 2% 미만: 희소

보너스:

- 부족 클래스: 시즌 소개/추천 노출 증가
- 희소 클래스: 클래스 도감 강조, 스트리머 프로필 배지
- 과밀 클래스: 보너스 없음

전투력이나 보상 기대값을 직접 올리는 희소 보너스는 신중하게 사용한다. 선택 분산을 위해 성능을 흔들면 유저가 메타를 추적하게 된다.

## 7. 추천 클래스 시스템

스트리머가 빌드를 처음 설정할 때 추천 클래스 3개를 보여준다.

추천 기준:

- 현재 부족한 역할군
- 유저 파티에서 많이 비는 기여 축
- 이번 시즌 콘텐츠에서 노출을 늘리고 싶은 역할
- 스트리머가 가진 카드 이미지 분위기
- 입문 난이도

추천 UI:

- `현재 부족한 역할`
- `이번 시즌 추천`
- `입문자에게 쉬움`
- `고급 조합용`

추천은 강제하지 않는다. 추천 클래스를 선택하면 성능 보상이 아니라 노출/배지/도감 강조 같은 비경제 보상을 준다.

## 8. 클래스별 시즌 미션

역할별로 다른 기여 미션을 둔다.

| 역할군 | 시즌 미션 |
| --- | --- |
| 선봉 | 누적 보호량, 피해 흡수 |
| 타격 | 보스 피해, 정예 처치 |
| 속공 | 원정 시간 단축, 선제 행동 |
| 지원 | 회복량, 보호막량 |
| 방해 | 디버프 성공, 패턴 지연 |
| 술식 | 조건 발동, 누적 폭발 |
| 전략 | 시너지 발동, 조건 성공 |
| 탐사 | 추가 보상 발견, 시즌 조사 점수 |

전체 랭킹 하나만 두면 딜러가 유리하다. 역할군별 랭킹과 보상을 나눠야 한다.

## 9. 유저 수요 분산 장치

스트리머가 다양한 클래스를 고르게 하려면 유저가 다양한 클래스를 원해야 한다.

### 9.1 전 지역 기여처

모든 지역은 모든 역할군의 기여처를 가진다.

- 선봉: 피해 흡수, 사고 완화, 장기 원정 안정
- 타격: 적 처치, 정예/보스 돌파, 시간 단축
- 속공: 선제 행동, 이동/전투 템포, 짧은 원정 효율
- 지원: 회복, 보호막, 디버프 완화, 파티 유지
- 방해: 적 강화 약화, 상태이상, 위험 패턴 지연
- 술식: 조건부 고점, 누적 효과, 변수 대응
- 전략: 선택지 보정, 역할 시너지, 실패 원인 보완
- 탐사: 보상 발견, 경로 선택, 정보 힌트, 시즌 조사

### 9.2 도감 보너스

유저가 다양한 클래스 카드를 모으면 작은 계정 보너스를 받는다.

예:

- 역할군 8종 보유: 원정 정보 힌트 +1개
- 클래스 10종 보유: 시즌 도감 배지
- 클래스 20종 보유: 프론티어 프로필 장식
- 클래스 30종 보유: 특별 칭호

도감 보너스는 전투력/보상 기대값보다 정보, 장식, 편의 위주로 둔다.

### 9.3 파티 시너지

특정 조합을 금지하지 않고, 조합별 장단점을 만든다.

예:

- 역할군 4종: 전반적인 안정성 증가
- 선봉 2장: 피해 완화 증가, 전투 돌파는 다른 역할에 의존
- 타격 2장: 전투 돌파 증가, 장기 원정 안정성은 낮음
- 지원 2장: 생존 증가, 시간 단축은 낮음
- 탐사 2장: 보상/정보 증가, 전투 돌파는 낮음

중요한 점은 어떤 조합도 금지하지 않는 것이다. 같은 역할 4장 파티도 가능하되, 그 파티는 특정 축에 매우 강하고 다른 축에서 약해진다.

## 10. 시세 배제 원칙

프론티어에서 시세는 성능, 보상, 코스트, 성공률에 영향을 주지 않는다.

이유:

- 시세는 기존 치카포 경제와 연결되어 있어 프론티어 밸런스를 흔들 수 있다.
- 고시세 카드만 쓰이는 구조를 만들 수 있다.
- 스트리머 활동량 변화가 원정 성능을 흔들면 유저가 통제할 수 없는 불안정성이 생긴다.
- 프론티어는 카드의 경제 가치가 아니라 클래스 빌드와 파티 조합의 게임으로 분리되어야 한다.

허용되는 사용:

- 카드 상세에서 기존 시세를 표시하는 것
- 프론티어와 별도인 마켓/랭킹 화면으로 이동하는 링크
- 세계관 텍스트나 지역 콘셉트에만 사용하는 것

사용하지 않는 항목:

- 시세를 전투력에 반영
- 시세를 파티 코스트에 반영
- 시세를 보상량에 반영
- 시세를 성공률에 반영
- 시세를 추천 파티에 반영

## 11. 별 등급 밸런스

별 등급은 유의미해야 하지만 저성 카드도 쓸 수 있어야 한다.

권장:

- 별 등급은 계수 증가와 연출 중심
- 특정 기능을 고성에만 잠그지 않는다
- 5성 카드는 강하지만 파티 전체 다양성 보너스를 독점하지 않는다
- 저성 카드는 낮은 성장 비용, 도감, 역할 보완, 접속 개입 효율로 쓰임새를 준다

## 12. 파티 코스트 정책

파티 코스트는 오토리그 같은 경쟁 콘텐츠에서만 신중하게 사용한다. 원정에서는 가능하면 코스트 제한을 두지 않는다.

코스트를 사용하더라도 시세는 절대 포함하지 않는다.

코스트 후보 요소:

- 별 등급
- 패시브 위험도
- 시즌 특수 규칙
- 동일 역할군 과밀 정도

원정 기본 모드는 코스트보다 `점수 축의 불균형`으로 밸런스를 맞춘다.

## 13. 특정 조합 금지 대신 점감

특정 패시브/클래스 조합을 금지하지 않는다. 대신 같은 효과 축이 중첩될수록 효율을 낮춘다.

점감 예시:

- 첫 번째 보상 증가 효과: 100% 효율
- 두 번째 보상 증가 효과: 60% 효율
- 세 번째 보상 증가 효과: 30% 효율
- 네 번째 이후: 10% 효율 또는 정보 보너스로 전환

다른 축도 같은 원칙을 적용한다.

- 추가 행동: 행동 게이지 획득량 점감
- 보호막: 최대 보호막 상한 적용
- 회복: 초과 회복은 낮은 비율로 보호막 전환
- 디버프: 같은 디버프 중첩 시 지속시간/성공률 점감
- 시간 단축: 전체 단축률 상한 적용
- 희귀 보상: 합연산 상한 적용

## 14. 보상형 클래스 밸런스

탐사/보상 계열은 반드시 상한과 점감이 필요하다.

상한:

- 추가 보상 슬롯은 원정당 최대 1개
- 희귀 보상 확률은 총합 상한 적용
- 시간 단축은 총합 10~15% 상한
- 실패 보상 보존은 최대 50% 이하

단, 이를 “조합 금지”로 표현하지 않는다. 같은 계열을 많이 넣으면 보상 효율은 점감하지만, 정보 힌트, 안정성, 이벤트 선택지 같은 보조 가치로 일부 전환한다.

## 15. 오토리그 밸런스

오토리그는 가장 밸런스가 민감하다.

출시 전 필수:

- 전투 로그
- 클래스별 승률 통계
- 패시브별 승률 통계
- 역할군별 기여 통계
- 방어 파티와 공격 파티 구분
- 점감/상한 규칙

오토리그에서도 특정 조합 금지보다 시즌 룰, 점감, 맵/상대 매칭, 카운터 구조로 조정한다.

## 16. 밸런스 지표

관리자는 아래 지표를 봐야 한다.

- 클래스 선택률
- 역할군 선택률
- 패시브 선택률
- 클래스별 원정 성공률
- 클래스별 평균 보상 기대값
- 클래스별 레이드 기여도
- 클래스별 오토리그 승률
- 상위 5% 유저의 편성 고착도
- 지역별 판정 축 실패율
- 별 등급별 사용률
- 동일 효과 축 중첩률

시세 구간별 사용률은 프론티어 밸런스 지표에서 제외한다.

## 17. 조정 정책

특정 조합 금지보다 먼저 점감과 콘텐츠 판정 비중을 조정한다.

우선순위:

1. 지역별 판정 축 비중을 조정한다.
2. 접속 개입으로 보완 가능한 축을 늘린다.
3. 점감 곡선을 조정한다.
4. 역할별 기여 보상을 조정한다.
5. 클래스 계수를 조정한다.
6. 심각한 버그성 무한 루프만 수정한다.

시즌 중 대규모 너프는 신뢰를 해친다. 가능하면 시즌 종료 시 반영한다.

## 18. 스트리머 변경 정책

스트리머 클래스 변경은 자유롭되 남용은 막는다.

권장:

- 시즌 시작 전 자유 변경
- 시즌 중 무료 변경 1회
- 이후 변경은 쿨다운 또는 프론티어 재화 필요
- 부족 클래스 전환은 추천 노출을 강화
- 과밀 클래스 전환은 막지 않되 별도 성능 페널티를 주지 않음

진행 중인 원정/전투는 시작 시점 스냅샷을 사용하므로 변경 영향을 받지 않는다.

## 19. 커뮤니케이션 원칙

밸런스 정책은 유저와 스트리머에게 이해 가능해야 한다.

좋은 표현:

- “이 지역은 모든 역할군이 기여하지만, 이번 단계는 생존 판정 비중이 높습니다.”
- “같은 효과를 많이 쌓으면 효율이 점점 낮아집니다.”
- “시세는 프론티어 성능에 영향을 주지 않습니다.”
- “보상형 효과는 상한 이후 정보/편의 보너스로 전환됩니다.”

피해야 할 표현:

- “이 조합은 너무 강해서 막았습니다.”
- “이 지역은 특정 역할만 필요합니다.”
- “시세가 높아서 프론티어 성능이 달라집니다.”
- “시스템상 불가능합니다.”
