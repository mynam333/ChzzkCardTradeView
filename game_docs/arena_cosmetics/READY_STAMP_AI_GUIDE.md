# 아레나 턴 준비 스탬프 제작 가이드

## 목적

턴 준비 스탬프는 행동 제출 완료 시 표시되는 짧은 피드백 치장이다.

## 제작 지시

- 이미지 없이 텍스트, 링, 잠금 애니메이션으로 구현한다.
- `READY`, `LOCKED`, `SET`처럼 짧은 문구를 사용한다.
- 내 필드 또는 플레이어 HUD 근처에 0.8~1.2초 표시한다.
- 상대에게도 준비 완료 상태를 직관적으로 알려준다.
- 전투 시작 시 자동으로 사라진다.

## 권장 CSS 구조

```json
{
  "presetKey": "ready-stamp-royal-lock",
  "durationMs": 1000,
  "text": "READY",
  "primaryColor": "#fbbf24",
  "ringColor": "#fff7ed",
  "motion": "scale-lock"
}
```

## 품질 기준

- UX 피드백 기능을 겸하므로 눈에 잘 띄어야 한다.
- 상대의 남은 시간, 체력, 코스트 UI를 가리지 않는다.
- 동일 턴에 중복 표시되지 않아야 한다.
