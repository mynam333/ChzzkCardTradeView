# 아레나 네임플레이트 제작 가이드

## 목적

네임플레이트는 매치 상단의 플레이어 이름 영역을 고급스럽게 꾸미는 치장 아이템이다.

## 제작 지시

- 이미지 없이 CSS 배경, 라인, 글로우, 장식 아이콘 느낌으로 구현한다.
- 플레이어명, 체력, MMR 등 핵심 정보가 읽혀야 한다.
- 너무 큰 장식으로 전장 면적을 줄이지 않는다.
- 이름 길이에 대응하기 위해 말줄임과 최소 너비를 고려한다.

## 권장 CSS 구조

```json
{
  "presetKey": "nameplate-obsidian-crown",
  "background": "linear-gradient(135deg,rgba(15,23,42,.94),rgba(30,41,59,.78))",
  "accentColor": "#38bdf8",
  "trimColor": "#facc15",
  "glow": "medium"
}
```

## 품질 기준

- 라이트/다크 모드에서 모두 정보가 명확해야 한다.
- 상대 네임플레이트와 내 네임플레이트가 시각적으로 충돌하지 않아야 한다.
- 전투 화면에서 가장 중요한 카드와 HP보다 과하게 튀면 안 된다.
