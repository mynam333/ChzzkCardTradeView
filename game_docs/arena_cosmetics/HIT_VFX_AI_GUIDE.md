# 아레나 타격 VFX 제작 가이드

## 목적

타격 VFX는 카드가 상대를 공격할 때 타격감과 구매 체감을 크게 높이는 코드 기반 치장 아이템이다.

## 제작 지시

- 이미지 없이 DOM/CSS 또는 canvas 파라미터로 구현한다.
- 효과 지속시간은 350~800ms로 제한한다.
- 카드와 HP 숫자를 가리지 않도록 중앙에서 빠르게 터지고 사라지게 한다.
- 충격 링, 베기 궤적, 파편, 짧은 플래시를 조합한다.
- 여러 타격이 동시에 발생해도 프레임 드랍이 없도록 요소 수를 제한한다.

## 권장 파라미터

```json
{
  "presetKey": "hit-vfx-starbreaker",
  "durationMs": 620,
  "ringColor": "#fde68a",
  "slashColor": "#fb7185",
  "particleColor": "#f97316",
  "particleCount": 10,
  "screenShake": "light"
}
```

## 품질 기준

- 피해 숫자와 동시에 보여도 숫자가 읽혀야 한다.
- 한 턴에 12회 이상 발동해도 UI가 버벅이지 않아야 한다.
- 이펙트가 전투 결과를 오해하게 만들면 안 된다.
- 기본 타격 VFX보다 색상, 형태, 리듬이 확실히 달라야 한다.
