# 아레나 KO 문구 제작 가이드

## 목적

KO 문구는 카드 처치 또는 승리 순간에 짧게 나타나는 텍스트 연출이다.

## 제작 지시

- 이미지 없이 텍스트, 그림자, 충격파로 구현한다.
- 문구는 1~2단어 이내로 제한한다.
- 처치/승리 판정과 동기화되어야 하며, 판정 전에는 절대 표시하지 않는다.
- 지속시간은 700~1200ms로 제한한다.
- 반복 전투 상황에서 피로하지 않도록 큰 화면 흔들림은 피한다.

## 권장 파라미터

```json
{
  "presetKey": "ko-text-crimson-finish",
  "text": "FINISH",
  "durationMs": 980,
  "primaryColor": "#fb7185",
  "impactColor": "#ef4444",
  "motion": "impact-slice"
}
```

## 품질 기준

- 승리/처치의 쾌감이 즉시 느껴져야 한다.
- 전투 로그와 피해 숫자를 완전히 덮지 않는다.
- 문구가 길어져도 모바일 화면 밖으로 나가지 않아야 한다.
