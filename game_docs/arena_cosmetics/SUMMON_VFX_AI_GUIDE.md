# 아레나 소환 VFX 제작 가이드

## 목적

소환 VFX는 카드를 필드에 배치할 때 짧게 나타나는 연출로, 플레이어가 새 카드를 냈다는 순간을 멋지게 만든다.

## 제작 지시

- 이미지 없이 CSS 원형 링, 라인 스캔, 파티클로 구현한다.
- 카드가 놓인 칸 안에서만 재생한다.
- 지속시간은 450~900ms로 제한한다.
- 필드 칸 경계와 카드 이미지를 가리지 않는다.
- 소환 완료 후 잔상이 남지 않게 한다.

## 권장 파라미터

```json
{
  "presetKey": "summon-vfx-circuit-gate",
  "durationMs": 720,
  "primaryColor": "#38bdf8",
  "secondaryColor": "#2dd4bf",
  "ringCount": 2,
  "scanLine": true,
  "particleCount": 8
}
```

## 품질 기준

- 카드 배치가 확정됐다는 피드백이 즉시 느껴져야 한다.
- 전술 이동/교체와 혼동되지 않는 고유한 등장 패턴을 가진다.
- 모바일에서 1칸 크기 안에 들어가야 한다.
