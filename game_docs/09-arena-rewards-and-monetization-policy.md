# 치카포 아레나 보상 및 수익화 정책

## 1. 목적

이 문서는 치카포 아레나의 시즌 보상, 랭크 보상, 플레이 보상, 코스메틱 보상, 치카포 본편 연동 보상, 수익화 가능 범위와 금지 범위를 정의한다.

치카포 아레나는 경쟁형 카드 오토배틀러이므로 수익화와 보상이 전투력에 영향을 주면 안 된다. 모든 보상과 상품은 공정성을 해치지 않는 외형, 기록, 편의, 커뮤니티 표현 중심으로 설계한다.

## 2. 절대 원칙

### 2.1 Pay to Win 금지

아레나에서 구매하거나 보상으로 얻은 것이 전투 승률을 직접 올리면 안 된다.

금지:

- 유료 전용 강한 카드
- 유료 전용 스킬
- 유료 전용 클래스
- 유료 스탯 증가
- 유료 MMR 보호권
- 유료 랭크 점수 부스트
- 유료 매칭 우선권
- 유료 reroll로 강한 카드 획득
- 치카포 본편 고가 카드 보유에 따른 아레나 전투력 보너스

허용:

- 카드 스킨
- 보드 스킨
- 리플레이 이펙트
- 프로필 배너
- 칭호
- 감정표현
- 덱 슬롯 확장. 단, 전투 중 선택지는 동일해야 함
- 전투 결과 연출
- 시즌 패스의 외형 보상

### 2.2 본편 연동 범위

치카포 본편과 아레나는 연결될 수 있지만, 연결은 외형과 정체성 중심이어야 한다.

본편에서 가져올 수 있는 것:

- 스트리머 카드 이미지
- 커스텀 카드 이미지
- 카드 테두리
- 이름 효과
- 칭호성 코스메틱
- 유저 프로필 표시

본편에서 가져오면 안 되는 것:

- 카드 시세 기반 전투력
- 팔로워 기반 전투력
- 방송 중 버프
- 보유 카드 수량 기반 전투력
- 포인트 기반 강화
- 마켓 구매 기반 전투력

## 3. 보상 종류

### 3.1 랭크 보상

랭크 보상은 시즌 종료 시 지급한다.

보상 후보:

- 시즌 칭호
- 프로필 배너
- 카드 프레임 스킨
- 이름표 효과
- 전투 입장 연출
- 리플레이 MVP 연출
- 시즌 기록 배지

보상 기준:

```text
최종 티어
최고 티어
최소 플레이 수
어뷰징 여부
제재 여부
```

권장:

- 시즌 보상은 `최고 티어` 기준으로 지급
- 랭킹 상위권 특별 보상은 `최종 순위` 기준
- 최소 랭크 매치 수 조건 필요

예:

```text
Bronze: 시즌 참가 배지
Silver: 시즌 프로필 장식
Gold: 시즌 카드 프레임
Platinum: 시즌 이름효과
Diamond: 전투 입장 연출
Master: 한정 칭호
Top 100: 순위 각인 배너
```

### 3.2 플레이 보상

플레이 보상은 랭크 참여를 장려하되, 반복 플레이 강제와 어뷰징을 막아야 한다.

허용:

- 일일 첫 봇전 완료 보상. 소량
- 일일 첫 랭크 완료 보상. 승패 무관
- 주간 미션 보상
- 시즌 미션 보상

금지:

- 승리할 때마다 큰 포인트 지급
- 무제한 반복 가능한 포인트 보상
- 봇전 무한 파밍
- 랭크 점수를 보상으로 직접 지급

권장:

```text
일일 보상: 계정당 1회
주간 보상: 계정당 제한
봇전 보상: 튜토리얼/첫 완료 중심
랭크 보상: 결과보다 참여와 시즌 성취 중심
```

### 3.3 업적 보상

아레나 전용 업적을 둘 수 있다.

예:

- 첫 봇전 완료
- 첫 빠른대전 완료
- 첫 랭크 승리
- 5판 3선승에서 3:2 승리
- 특정 태그 4단계 덱으로 승리
- 세트 리플레이 10회 시청
- 덱 5개 저장

보상:

- 칭호
- 프로필 배지
- 보드 장식
- 외형 코스메틱

업적 보상이 전투력을 주면 안 된다.

## 4. 시즌 패스

### 4.1 목적

시즌 패스는 아레나의 수익화 수단이 될 수 있다. 단, 전투력 보상은 포함하지 않는다.

무료 트랙:

- 기본 시즌 보상
- 일부 칭호
- 기본 프로필 배지
- 소량 치카포 본편 코스메틱

프리미엄 트랙:

- 추가 카드 프레임 스킨
- 보드 스킨
- 리플레이 이펙트
- MVP 연출
- 프로필 배너
- 감정표현
- 덱 슬롯 추가

금지:

- 프리미엄 전용 강한 카드
- 프리미엄 전용 스킬
- 프리미엄 전용 랭크 보호
- 프리미엄 전용 매칭 우선권

### 4.2 진행도

진행도 획득:

- 랭크 완료
- 봇전 일일 첫 완료
- 주간 미션
- 시즌 미션

진행도 제한:

- 하루 획득량 상한 가능
- 봇전 반복 획득 제한
- 비정상 매치 제외

## 5. 상점 상품

### 5.1 판매 가능 상품

판매 가능:

- 보드 스킨
- 카드 프레임 스킨
- 이름표 효과
- 리플레이 컷인
- MVP 화면 연출
- 감정표현
- 프로필 배너
- 덱 슬롯
- 전투 기록 보관 확장. 단, 서버 부하 고려

### 5.1.1 아레나 내부 포인트 상점 MVP

아레나 아이템은 아레나 화면 안에서 구매, 확인, 장착할 수 있어야 한다.

MVP 구현:

- 아레나 스타일 상점
- 프로필 프레임 구매
- 이름 연출 구매
- 배틀 이모트 구매
- 보유 수량 확인
- 구매 제한 확인
- 아레나 장착/해제
- 장착 미리보기

API:

```text
GET   /api/arena/cosmetics/shop-items
GET   /api/arena/cosmetics/inventory-counts
GET   /api/arena/cosmetics/purchases
GET   /api/arena/cosmetics/loadout
PATCH /api/arena/cosmetics/loadout
POST  /api/arena/cosmetics/buy
WS    /arena/realtime
```

장착 정보는 `arena_user_cosmetic_loadouts`에 저장한다. 이 테이블은 `border_item_id`, `name_effect_item_id`, `emote_slot_1_item_id`부터 `emote_slot_4_item_id`까지의 표시용 슬롯만 가진다. 전투, 매칭, MMR, 랭킹, 보상 계산에서 읽지 않는다.

배틀 이모트 사용 이벤트는 `/arena/realtime`에서 DB 저장 없이 메모리 룸 브로드캐스트로만 처리한다.

### 5.2 판매 금지 상품

판매 금지:

- MMR 부스트
- 승리 보정
- 강한 봇전 보상권
- 카드 능력 변경권
- 스킬 직접 선택권
- 시너지 태그 강화권
- 특정 상대 회피권
- 매칭 우선권

스트리머 카드 설정권도 판매 상품이 되면 안 된다. 스트리머 본인의 권리로 제공되어야 한다.

## 6. 치카포 본편 보상 연동

아레나 보상은 일부 본편 코스메틱으로 연동할 수 있다.

허용 예:

- 아레나 시즌 칭호를 치카포 프로필에 표시
- 아레나 시즌 프레임을 치카포 카드 외형에 사용
- 아레나 상위 랭커 이름효과
- 아레나 참가 배지

주의:

- 본편 경제를 과도하게 흔들지 않도록 포인트 보상은 제한한다.
- 카드 지급 보상은 신중해야 한다.
- 아레나 보상이 본편 마켓 가격에 영향을 줄 수 있으므로 한정 외형 중심이 안전하다.

권장:

```text
아레나 -> 본편: 외형/칭호 중심
본편 -> 아레나: 이미지/코스메틱 표시 중심
```

## 7. 보상 지급 조건

시즌 보상 지급 전 검증:

- 최소 랭크 매치 수
- 제재 여부
- 어뷰징 탐지 여부
- 비정상 매치 제외
- 계정 상태

권장 최소 조건:

```text
시즌 보상: 랭크 10세트 이상
상위 랭킹 보상: 랭크 30세트 이상
승률 랭킹 노출: 랭크 50세트 이상
```

## 8. 어뷰징 방지

보상은 어뷰징을 유발할 수 있다.

위험:

- 다계정으로 서로 져주기
- 봇전 반복 파밍
- 큐 저격으로 점수 조작
- 시즌 종료 직전 조작 매치
- 보상 목적 잠수 플레이

대응:

- 같은 상대 반복 매칭 감시
- 짧은 시간 다수 매치 감시
- 비정상 3:0 반복 감시
- 봇전 보상 제한
- 최소 플레이 시간/이벤트 기준
- 제재 계정 보상 제외

## 9. 경제 영향 제한

아레나가 본편 경제를 흔들면 안 된다.

포인트 보상 원칙:

- 아레나 랭크 반복 플레이로 본편 포인트를 무한 생산하지 않는다.
- 포인트 보상은 이벤트성 또는 제한형으로 둔다.
- 가능한 외형 보상 중심으로 설계한다.

카드 보상 원칙:

- 특정 스트리머 카드를 경쟁 보상으로 지급하면 논란이 생길 수 있다.
- 카드 보상은 랜덤 박스보다 선택권/교환권이 더 안전할 수 있지만, 본편 경제 영향 검토가 필요하다.
- MVP에서는 카드 보상을 제외하는 것이 안전하다.

## 12. MVP 범위

MVP 포함:

- 시즌 티어 보상
- 시즌 랭킹 보상
- 기본 업적 보상
- 일일 첫 플레이 미션
- 외형 중심 보상

MVP 제외:

- 유료 시즌 패스
- 유료 상점
- 본편 포인트 대량 보상
- 카드 지급 보상
- 전투력 관련 모든 상품

유료화는 게임 밸런스와 리텐션이 안정된 뒤 도입한다.

## 13. 반드시 지켜야 할 결정 사항

1. 아레나 수익화는 전투력을 팔지 않는다.
2. 시즌 보상은 외형, 칭호, 기록 중심으로 설계한다.
3. 봇전과 랭크 반복 플레이가 본편 재화를 무한 생산하면 안 된다.
4. 스트리머 카드 설정권은 판매 상품이 아니다.
5. 본편과의 보상 연동은 외형/칭호 중심이 안전하다.
6. 보상 지급 전 어뷰징 검증을 수행한다.
7. MVP에서는 유료화보다 공정한 랭크와 리텐션 검증을 우선한다.
