# 치카포 이스터에그 기획서

## 1. 목표

치카포의 카드 수집, 가챠, 오픈마켓, 404 페이지, 키보드 조작, 검색 흐름 안에 숨겨진 장난성 기능을 추가한다.

핵심 목표는 세 가지다.

- 발견하지 못해도 서비스 이용에 아무 영향이 없어야 한다.
- 발견했을 때는 치카포 세계관에 어울리는 별도 레이어를 연 느낌을 준다.
- 실제 포인트, 카드, 거래, 랭킹, 쿠폰, 관리자 기능에는 영향을 주지 않는다.

이번 이스터에그의 전체 콘셉트는 `이스터에그 신호`다. 치카포 화면 곳곳에 카드 단말기, 분실 카드, 방송 송출실 같은 흔적이 숨어 있고, PC 사용자가 서로 다른 화면 맥락에서 각기 다른 방식으로 그 신호를 찾는 구조다.

## 2. 디자인 원칙

- 이스터에그는 재미용이며 실제 보상처럼 보이면 안 된다.
- 포인트, 카드, 코스메틱, 쿠폰을 지급하지 않는다.
- 발견 기록은 기본적으로 `localStorage`에만 저장한다.
- 서버 API와 DB를 새로 쓰지 않는 클라이언트 전용 기능으로 1차 구현한다.
- 모바일은 적극적으로 배려하지 않는다. 모바일에서는 대부분의 이스터에그가 보이지 않거나 발동하기 어렵게 둔다.
- 발동 조건은 기능마다 겹치지 않게 설계한다. 모든 이스터에그를 검색 명령어나 키보드 입력으로만 열지 않는다.
- 접근성이나 기본 사용성을 깨면 안 된다. 입력창, 버튼, 거래 확인, 가챠 실행 등 주요 흐름을 방해하지 않는다.
- 관리자 화면, 신고 화면, 결제성/자산성 액션에는 이스터에그 발동을 넣지 않는다.

## 3. 모바일 정책

이번 이스터에그는 PC 중심 숨김 기능으로 설계한다.

모바일 정책:

- 키보드 콤보 이스터에그는 모바일에서 지원하지 않는다.
- 모바일 하단 도크에는 이스터에그 힌트나 진입 버튼을 추가하지 않는다.
- 모바일 검색창에서도 단말기 코드 처리는 기본적으로 비활성화한다.
- 모바일 404 페이지는 일반적인 분실 카드 화면만 보여주고, 추가 해금 연출은 데스크톱에서만 활성화한다.
- 화면 폭이 `768px` 미만이면 전역 이스터에그 감지기를 끈다.
- 개발 편의를 위해 모바일 강제 테스트가 필요하면 `?easterEggDebug=1` 같은 쿼리로만 임시 활성화한다. 운영 노출은 기본 비활성이다.

기준 구현:

```ts
const isDesktopEasterEggSurface =
  typeof window !== 'undefined' &&
  window.matchMedia('(min-width: 768px)').matches;
```

## 4. 이스터에그 목록

1차 구현 대상은 아래 다섯 가지다.

- 숨겨진 레어 테마: `이스터에그 모드`
- 검색창 비밀 코드: `카드 단말기 코드`
- 404 페이지: `분실 카드 보관소`
- 키보드 콤보: `치카포 단말기 부팅 코드`
- 오늘의 카드 운세: `오늘의운세`

각 기능은 아래처럼 서로 다른 발견 방식을 가진다.

| 기능 | 발견 방식 | 어울리는 이유 |
| --- | --- | --- |
| 이스터에그 모드 | PC 사이드바 치카포 로고 7회 클릭 | 브랜드 로고를 건드렸을 때 사이트 뒤편 테마가 열린다는 느낌 |
| 카드 단말기 코드 | 오픈마켓 검색창에 카드 번호형 코드 입력 | 장터에서 없는 카드를 검색하다 단말기 로그를 발견하는 흐름 |
| 분실 카드 보관소 | 존재하지 않는 경로 진입 또는 `No.0404` 코드 | 404 자체를 잃어버린 카드 보관소로 해석 |
| 치카포 단말기 부팅 코드 | 고전 키보드 콤보 입력 | PC 사용자만 발견하기 쉬운 숨은 조작 |
| 오늘의운세 | 메인 히어로의 `매일 무료 가챠` 뱃지 3회 클릭 | 일일 무료 가챠와 오늘의 운세가 자연스럽게 연결됨 |

## 5. 숨겨진 레어 테마: 이스터에그 모드

### 개요

치카포의 일반 라이트/다크 테마 위에 잠깐 덧씌워지는 특수 테마다. 사용자는 치카포 내부의 숨겨진 카드 단말기를 발견한 것처럼 느낀다.

### 발동 조건

PC에서만 발동한다.

- PC 사이드바 상단의 치카포 로고 영역을 7초 안에 7회 클릭
- 마지막 클릭 시 로고가 0.4초 동안 미세하게 흔들리고 이스터에그 모드가 켜짐
- 이미 켜진 상태에서 같은 동작을 다시 하면 즉시 해제
- 404 페이지의 분실 카드를 PC에서 4회 뒤집어도 켜짐

기존 `숨은신호`라는 명칭은 사용하지 않는다. 모든 UI 문구와 코드 네이밍은 `이스터에그` 기준으로 통일한다.

검색창 명령어로는 이스터에그 모드를 직접 켜지 않는다. 테마는 브랜드 로고와 404 분실 카드에서만 열리는 숨겨진 상태로 둔다.

### 지속 시간

- 기본 5분
- 사용자가 직접 끌 수 있음
- 페이지 새로고침 후에는 꺼짐
- 단, `localStorage`에는 발견 기록만 남김

### 화면 효과

전역:

- `html` 또는 `body`에 `easter-egg-mode` 클래스 추가
- 배경에 아주 약한 스캔라인
- 주요 카드/패널에 민트, 하늘색, 노란색이 섞인 미세한 발광
- 사이드바 활성 메뉴에 `ON AIR` 느낌의 점멸 점 표시
- 마우스 커서를 따라다니는 효과는 넣지 않는다. 사용성을 해칠 가능성이 높다.

카드 영역:

- 카드 썸네일 hover 시 기존보다 조금 더 강한 홀로그램 광택
- 카드 테두리 주변에 1초 이하의 짧은 반짝임
- 거래 버튼, 구매 버튼, 신고 버튼 같은 액션 버튼에는 효과를 적용하지 않는다.

상단 또는 토스트:

- 발동 시 토스트: `이스터에그 신호를 수신했습니다.`
- 해제 시 토스트: `이스터에그 모드를 종료했습니다.`

### CSS 방향

색상은 기존 치카포의 하늘색/민트 계열을 유지하되, 화면 전체가 한 가지 색으로 덮이지 않게 한다.

```css
html.easter-egg-mode {
  --easter-egg-glow: 22 214 190;
  --easter-egg-warn: 250 204 21;
}

html.easter-egg-mode body::before {
  content: "";
  pointer-events: none;
  position: fixed;
  inset: 0;
  z-index: 70;
  background:
    linear-gradient(rgba(255,255,255,0.035) 50%, rgba(0,0,0,0.025) 50%);
  background-size: 100% 4px;
  mix-blend-mode: soft-light;
}
```

## 6. 검색창 비밀 코드: 카드 단말기 코드

### 개요

오픈마켓 검색창에 카드 번호처럼 보이는 특정 코드를 입력하면 실제 검색 대신 카드 단말기 반응을 보여준다. 이 기능은 "장터에서 없는 카드를 찾다가 숨겨진 단말기가 응답했다"는 느낌으로 설계한다.

### 적용 위치

1차 적용:

- 상점 > 오픈마켓 매물 검색

적용 제외:

- 상점 코스메틱 검색
- 관리자 검색창
- 신고/제재 관련 검색창
- 쿠폰 입력창
- 로그인 콜백 페이지
- 친구 채팅 입력창

### 단말기 코드

| 입력값 | 동작 |
| --- | --- |
| `No.0404` | 단말기 로그 표시 후 존재하지 않는 카드 경로 `/cards/no-0404`로 이동해 404 진입 |
| `CARD://LOST` | 단말기 로그만 표시하고 검색창을 비움 |
| `LIVE?` | 3초 동안 `LIVE SIGNAL DETECTED` 배너 표시 |

기존 `오늘의운` 명칭은 사용하지 않는다. 모든 화면 문구와 명령어 별칭은 `오늘의운세`로 통일한다.

`/easteregg`, `이스터에그`, `/fortune`, `오늘의운세`, `카드운세`는 검색창 명령어로 처리하지 않는다. 이스터에그 모드와 오늘의운세는 각각 별도 발동 조건을 가진다.

### 처리 규칙

- PC에서만 처리한다.
- 단말기 코드가 감지되면 실제 검색 API를 호출하지 않는다.
- 단말기 코드 실행 후 검색창 값을 비운다.
- 단말기 코드 처리 여부를 반환하는 공용 유틸을 둔다.
- 일치하지 않는 값은 기존 검색 로직으로 넘긴다.

예상 유틸:

```ts
type EasterEggTerminalCode = 'lostCard' | 'terminalLog' | 'liveSignal';

export const resolveEasterEggTerminalCode = (raw: string): EasterEggTerminalCode | null => {
  const value = raw.trim().toUpperCase();
  if (value === 'NO.0404') return 'lostCard';
  if (value === 'CARD://LOST') return 'terminalLog';
  if (value === 'LIVE?') return 'liveSignal';
  return null;
};
```

## 7. 404 페이지: 분실 카드 보관소

### 현재 상태

현재 `frontend/src/app/not-found.tsx`는 정의되지 않은 경로를 바로 `/`로 리다이렉트한다.

### 변경 방향

리다이렉트를 제거하고 실제 404 페이지를 만든다. 이 페이지는 서비스의 dead-end가 아니라 `분실 카드 보관소`라는 이스터에그성 페이지로 사용한다.

### 진입 조건

- 사용자가 실제로 존재하지 않는 URL에 접근
- 오픈마켓 검색창에 `No.0404` 입력 후 `/cards/no-0404`로 이동
- 주소창에 `/lost-card`, `/cards/no-0404`, `/market/ghost-listing` 같은 없는 경로를 직접 입력

### 화면 구성

제목:

- `분실 카드 보관소`

보조 문구:

- `존재하지 않는 경로에서 낡은 카드 신호가 감지되었습니다.`

중앙 카드:

- 카드 번호: `No.0404`
- 카드 등급: `UNKNOWN`
- 카드 이름은 진입할 때 랜덤 선택
  - `깨진 링크의 카드`
  - `사라진 매물의 흔적`
  - `방송 종료 후 남은 신호`
  - `없는 페이지의 컬렉터`
  - `돌아오지 않은 검색 결과`

버튼:

- `메인으로`
- `상점으로`
- `카드 다시 확인`

### PC 전용 숨김 동작

PC에서 중앙 카드를 4회 뒤집으면 이스터에그 모드가 발동한다.

발동 문구:

- `No.0404 카드가 이스터에그 신호를 열었습니다.`

모바일에서는 카드 뒤집기는 가능하지만 4회 해금 카운트를 올리지 않는다.

## 8. 키보드 콤보: 치카포 단말기 부팅 코드

### 개요

PC 사용자가 화면 어디에서든 고전적인 키보드 콤보를 입력하면 숨겨진 카드 단말기 모달이 열린다.

### 입력

```text
ArrowUp ArrowUp ArrowDown ArrowDown ArrowLeft ArrowRight ArrowLeft ArrowRight KeyB KeyA
```

### 발동 제외 조건

아래 상황에서는 감지하지 않는다.

- 화면 폭이 `768px` 미만
- `input`, `textarea`, `select`, `contenteditable`에 포커스가 있음
- 모달이 이미 열려 있음
- 거래 확인, 구매 확인, 신고, 관리자 작업 같은 중요한 확인 모달이 열려 있음

### 성공 연출

- 화면이 0.4초 정도 카드 단말기처럼 깜빡임
- 작은 모달 표시

모달 제목:

- `치카포 단말기 부팅 완료`

모달 본문:

- `숨겨진 카드 단말기가 응답했습니다.`

모달 버튼:

- `부팅 로그 보기`
- `닫기`

부팅 로그 예시:

- `CHIKAPO TERMINAL READY`
- `MARKET SIGNAL: SEARCH CODE ACCEPTED`
- `LOST CARD INDEX: 0404`

### 실패 처리

- 입력 중간에 틀리면 버퍼를 초기화한다.
- 3초 이상 다음 키가 없으면 버퍼를 초기화한다.
- 실패 토스트는 띄우지 않는다. 숨겨진 기능이므로 조용해야 한다.

## 9. 오늘의 카드 운세: 오늘의운세

### 개요

사용자의 실제 카드 가치나 거래 결과와 무관한 재미용 운세다. 기존 명칭은 `오늘의운`이 아니라 `오늘의운세`로 통일한다.

### 발동 조건

PC에서만 발동한다.

- 메인 탭 히어로 영역의 `매일 무료 가챠` 뱃지를 5초 안에 3회 클릭
- 클릭한 날의 날짜 기준으로 오늘의운세가 열림
- 같은 날 다시 3회 클릭하면 같은 운세를 다시 보여줌

오늘의운세는 검색창이나 키보드 콤보에서 직접 열지 않는다. "오늘의 무료 가챠" 문맥에서 발견되는 장난으로 둔다.

### 결과 고정

- 같은 브라우저, 같은 날짜에는 같은 결과를 보여준다.
- `localStorage` 키: `chikapo:easter-egg:fortune:YYYY-MM-DD`
- 날짜 기준은 `Asia/Seoul`

### 운세 데이터 구조

```ts
type DailyFortune = {
  grade: '잔잔한 신호' | '반짝이는 신호' | 'LIVE 신호' | 'No.0000 신호';
  luckyTab: '상점' | '보관함' | '랭킹' | '미니게임' | '친구' | '내 정보';
  luckyColor: '민트' | '하늘색' | '노랑' | '분홍' | '흰색';
  message: string;
  caution: string;
};
```

### 문구 예시

잔잔한 신호:

- `오늘은 새 카드를 뽑기보다 보관함을 정리하기 좋은 날입니다.`
- `오래 안 본 카드가 생각보다 예뻐 보일 수 있습니다.`

반짝이는 신호:

- `관심 있던 카드가 자꾸 눈에 들어오는 날입니다.`
- `즐겨찾기 별표를 달아둘 카드가 생길 수 있습니다.`

LIVE 신호:

- `랭킹을 한 번 더 확인하면 재미있는 변화를 발견할 수 있습니다.`
- `오늘의 최애 신호가 평소보다 선명합니다.`

No.0000 신호:

- `카드 단말기가 잠깐 관리자도 모르는 표정을 지었습니다.`
- `없는 카드 번호가 오늘의 운세에 끼어들었습니다.`

주의 문구:

- `이 운세는 재미용이며 실제 카드 가치, 거래 결과, 가챠 결과와 관련이 없습니다.`

## 10. 발견 기록

1차는 서버 저장 없이 브라우저 로컬에만 저장한다.

키:

- `chikapo:easter-egg:discovered`
- `chikapo:easter-egg:firstSeenAt`
- `chikapo:easter-egg:lastSeenAt`
- `chikapo:easter-egg:terminalCodes`
- `chikapo:easter-egg:fortune:YYYY-MM-DD`

예시:

```json
{
  "theme": true,
  "keyboardBoot": true,
  "lostCard404": true,
  "fortune": true,
  "terminalLog": false,
  "liveSignal": false
}
```

발견 기록은 유저 계정에 귀속하지 않는다. 같은 계정이라도 브라우저가 다르면 다시 발견할 수 있다.

## 12. 이벤트 흐름

### 로고 연속 클릭

1. 사용자가 PC 사이드바 상단의 치카포 로고 영역을 7초 안에 7회 클릭
2. `MainLayout`이 클릭 횟수와 시간 창을 확인
3. `EasterEggProvider`에 `themeToggle` 이벤트 전송
4. 이스터에그 모드 토글
5. `theme` 발견 기록 저장

### 오픈마켓 단말기 코드

1. 사용자가 PC에서 오픈마켓 검색창에 `No.0404`, `CARD://LOST`, `LIVE?` 중 하나를 입력
2. 검색 submit 전에 `resolveEasterEggTerminalCode` 실행
3. 코드가 있으면 검색 API 호출 중단
4. `EasterEggProvider`에 커스텀 이벤트 전송
5. 코드별 단말기 로그, 404 이동, LIVE 배너 실행
6. `terminalCodes` 발견 기록 저장

커스텀 이벤트 예:

```ts
window.dispatchEvent(new CustomEvent('chikapo:easter-egg-command', {
  detail: { command: 'terminalCode', code: 'lostCard' }
}));
```

### 오늘의운세

1. 사용자가 PC에서 메인 탭 히어로의 `매일 무료 가챠` 뱃지를 5초 안에 3회 클릭
2. `MainTab`이 클릭 횟수와 시간 창을 확인
3. `EasterEggProvider`에 `fortune` 이벤트 전송
4. 오늘의운세 모달 표시
5. `fortune` 발견 기록 저장

### 키보드 콤보

1. `EasterEggProvider`가 `keydown` 감지
2. PC 여부와 포커스 상태 확인
3. 입력 버퍼와 정답 시퀀스 비교
4. 성공 시 단말기 부팅 모달 표시
5. `keyboardBoot` 발견 기록 저장

### 404 해금

1. 사용자가 존재하지 않는 경로 진입
2. `분실 카드 보관소` 표시
3. PC에서 중앙 카드 4회 클릭
4. 이스터에그 모드 발동
5. `lostCard404`, `theme` 발견 기록 저장

## 13. QA 체크리스트

기능:

- PC에서 사이드바 치카포 로고를 7초 안에 7회 클릭하면 이스터에그 모드가 켜진다.
- PC에서 이스터에그 모드가 켜진 상태로 같은 로고 동작을 반복하면 모드가 꺼진다.
- PC에서 오픈마켓 검색창에 `No.0404`를 입력하면 검색 API 호출 없이 404로 이동한다.
- PC에서 오픈마켓 검색창에 `CARD://LOST`를 입력하면 단말기 로그가 표시된다.
- PC에서 오픈마켓 검색창에 `LIVE?`를 입력하면 LIVE 배너가 표시된다.
- PC에서 메인 히어로의 `매일 무료 가챠` 뱃지를 5초 안에 3회 클릭하면 오늘의운세가 뜬다.
- 검색창에 `/easteregg`, `이스터에그`, `/fortune`, `오늘의운세`, `카드운세`를 입력해도 이스터에그가 발동하지 않는다.
- 기존 `오늘의운`은 발동하지 않는다.
- 기존 `숨은신호`는 발동하지 않는다.
- 단말기 코드 입력 시 검색 API가 호출되지 않는다.
- 일반 검색어는 기존처럼 검색된다.
- 키보드 콤보는 입력창 포커스 중에는 발동하지 않는다.
- 404 페이지에서 메인/상점 이동 버튼이 정상 동작한다.
- 이스터에그 모드는 5분 후 자동 해제된다.

모바일:

- 모바일에서 키보드 콤보 감지기가 동작하지 않는다.
- 모바일에서 오픈마켓 단말기 코드가 이스터에그로 처리되지 않는다.
- 모바일 404에서 카드 4회 클릭으로 이스터에그 모드가 켜지지 않는다.
- 모바일 하단 도크에 이스터에그 진입 UI가 없다.

안전:

- 포인트, 카드, 쿠폰, 코스메틱이 지급되지 않는다.
- 관리자 페이지에서는 단말기 코드가 처리되지 않는다.
- 구매/입찰/거래 확인 모달 위에 이스터에그 모달이 뜨지 않는다.
- `localStorage`를 사용할 수 없는 환경에서도 앱이 깨지지 않는다.

## 15. 2차 확장 아이디어

- 이스터에그 발견 횟수에 따라 404 카드 이름 후보 추가
- 특정 날짜에만 다른 오늘의운세 문구 표시
- 아케이드 탭에서만 발견 가능한 레트로 단말기 문구 추가
- `내 정보`에 노출하지 않는 숨겨진 로컬 배지 화면 추가
- 운영 이벤트 때만 `No.2026`, `EVENT://LIVE` 같은 임시 단말기 코드 추가

2차 확장에서도 실제 자산 보상은 지급하지 않는다. 이스터에그는 어디까지나 서비스 뒤편의 숨겨진 장난으로 유지한다.
