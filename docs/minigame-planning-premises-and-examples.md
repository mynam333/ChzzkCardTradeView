# 미니게임 기획 전제와 기존 게임 예시

작성일: 2026-09-17

회전 퍼즐, 카드 확대 탐정, 시세 듀얼을 교체하고 게임성을 높이는 방향으로 새로운 미니게임을 기획한다. 참고할 기존 게임은 **송출 오류난 스트리머 맞추기**와 **스트리머 짝맞추기** 두 가지다.

신규 게임의 공통 전제는 아래 세 가지로 정한다. 뒤에 설명하는 기존 게임의 라운드 수, 제한시간, 성공 조건, 보너스 달성 조건은 현재 게임을 이해하기 위한 예시이며, 신규 게임에 그대로 적용해야 하는 조건은 아니다.

## 1. 신규 게임의 공통 전제

### 1.1 기본 보상 1,000포인트와 보너스 200포인트

- 게임의 성공 조건을 달성하면 **1,000포인트**를 지급한다.
- 추가 보너스 조건까지 달성하면 **200포인트를 더해 총 1,200포인트**를 지급한다.
- 성공 조건과 보너스 조건은 각 게임의 규칙에 맞게 정한다. 보상 금액은 동일하게 유지한다.

### 1.2 사이트에 등록된 스트리머들의 이미지 사용

- 사이트에 등록된 스트리머들의 카드 이미지나 프로필 이미지를 게임에 사용한다.
- 이미지는 문제의 단서, 짝을 구분하는 그림, 조작할 대상 등 게임 규칙 안에서 활용한다.

### 1.3 직관적이고 이해하기 쉬운 규칙

- 플레이어가 무엇을 해야 하는지 쉽게 알 수 있어야 한다.
- 조작 방법과 성공 조건을 간단한 설명이나 예시로 이해할 수 있어야 한다.

## 2. 기존 게임 예시: 송출 오류난 스트리머 맞추기

### 게임 개요

**흐리게 보이는 스트리머 카드 이미지를 보고, 이름 두 개 중 해당 스트리머를 고르는 게임이다.**

사이트에 등록된 스트리머의 카드 이미지를 문제로 사용한다. 플레이어는 이미지에 남아 있는 얼굴, 캐릭터, 색상, 의상 등의 특징을 단서로 누구인지 판단한다. 선택지는 다른 이미지가 아니라 **스트리머 이름 두 개**다.

현재 정식 보상 게임은 흐림 처리된 이미지를 제시한다. 시간이 지나면 반드시 선명한 원본이 드러나는 규칙은 아니다.

### 화면 구성

- 현재 문제 번호와 누적 정답 수
- 해당 문제의 남은 시간
- 흐림 처리된 스트리머 카드 이미지 한 장
- 스트리머 이름이 적힌 선택 버튼 두 개
- 답을 고른 뒤 표시되는 정답·오답 결과와 다음 문제 버튼

### 플레이 순서

1. 카운트다운 후 첫 번째 문제의 이미지와 이름 보기 두 개가 나타난다.
2. 플레이어는 **10초 안에** 이미지 속 스트리머의 이름을 선택한다.
3. 선택한 이름이 맞으면 정답 수가 1개 증가한다. 틀리거나 시간 안에 답하지 못하면 해당 문제는 정답 수에 포함되지 않는다.
4. 결과를 확인하고 다음 문제로 넘어간다. 한 문제를 틀렸다고 게임 전체가 즉시 끝나지는 않는다.
5. 같은 방식으로 **총 5문제**를 진행한 뒤 최종 정답 수로 보상을 결정한다.

### 성공 조건과 보상

| 최종 결과 | 판정 | 지급 포인트 |
|---|---|---:|
| 0~2문제 정답 | 실패 | 0 |
| 3~4문제 정답 | 성공 | 1,000 |
| 5문제 모두 정답 | 성공 + 보너스 | 1,200 |

이 게임의 보너스는 **5문제를 모두 맞히는 것**으로 결정된다. 개별 문제를 더 빨리 맞혔다고 보상이 추가되지는 않는다.

### 플레이 예시

첫 문제에 특정 캐릭터가 그려진 흐린 카드가 나오고, 이름 보기로 ‘스트리머 A’와 ‘스트리머 B’가 제시된다. 플레이어는 캐릭터의 머리 모양과 대표 색상을 보고 A라고 판단해 선택한다. 실제 정답이 A이면 누적 정답 수가 1개가 된다.

이후 문제를 모두 풀어 최종적으로 4개를 맞혔다면 1,000포인트를 받는다. 5개를 모두 맞혔다면 보너스 200포인트를 포함한 1,200포인트를 받는다. A와 B는 설명을 위한 가상 표기이며, 실제 게임에서는 등록된 스트리머의 이름이 표시된다.

### 플레이어가 하는 판단

중심 행동은 **이미지의 특징을 알아보고 이름과 연결하는 것**이다. 조작은 이름 버튼을 누르는 것으로 단순하지만, 어떤 특징을 단서로 삼고 누구라고 판단할지가 게임의 내용이다. 스트리머나 해당 이미지를 알고 있는 경험이 정답 판단에 도움이 된다.

## 3. 기존 게임 예시: 스트리머 짝맞추기

### 게임 개요

**잠깐 공개된 카드의 위치를 기억한 뒤, 카드를 두 장씩 뒤집어 같은 스트리머의 짝을 모두 찾는 게임이다.**

사이트에 등록된 스트리머 **6명의 프로필 이미지**를 사용한다. 각 스트리머의 카드를 두 장씩 만들어 **총 12장, 6쌍**을 섞어 배치한다. 같은 쌍에는 같은 스트리머의 프로필 이미지가 나온다.

### 화면 구성

- 12장의 카드가 놓인 격자
- 남은 제한시간
- 이미 맞춘 카드 쌍과 아직 뒤집혀 있는 카드

카드 격자는 화면 크기에 따라 가로 3칸·세로 4칸 또는 가로 4칸·세로 3칸으로 표시된다. 처음에는 모든 카드의 앞면을 잠깐 보여주고, 이후 앞면을 가린 상태에서 시작한다.

### 플레이 순서

1. 카운트다운 후 모든 카드의 앞면을 **2초 동안 공개**한다. 플레이어는 각 이미지가 어디에 있는지 기억한다.
2. 카드가 다시 뒤집히면 **30초 제한시간**이 시작된다. 처음 공개하는 2초는 이 30초에 포함되지 않는다.
3. 플레이어가 카드 한 장을 누르면 앞면이 보인다. 이어서 다른 카드 한 장을 눌러 두 장을 비교한다.
4. 같은 스트리머의 카드라면 짝을 맞춘 것으로 처리하고 앞면을 유지한다. 해당 쌍은 다시 맞힐 필요가 없다.
5. 다른 스트리머의 카드라면 잠깐 앞면을 보여준 뒤 두 장을 다시 뒤집는다. 플레이어는 방금 확인한 위치를 기억하고 다음 선택에 활용할 수 있다.
6. 제한시간 안에 **6쌍을 모두 찾으면 성공**이다. 시간이 끝날 때까지 모든 쌍을 찾지 못하면 실패한다.

### 성공 조건과 보상

| 최종 결과 | 판정 | 지급 포인트 |
|---|---|---:|
| 30초 안에 6쌍을 모두 찾지 못함 | 실패 | 0 |
| 10초를 초과하고 30초 이내에 6쌍 완성 | 성공 | 1,000 |
| 10초 이내에 6쌍 완성 | 성공 + 보너스 | 1,200 |

이 게임의 보너스는 **모든 짝을 완성하는 데 걸린 시간**으로 결정된다. 중간에 잘못된 두 장을 골랐더라도 다시 시도할 수 있으며, 실수 횟수 자체가 별도의 포인트 감점 조건은 아니다.

### 플레이 예시

처음 2초 동안 다음과 같은 카드 배치를 보았다고 가정한다. 같은 문자는 같은 스트리머의 프로필 이미지를 뜻하는 설명용 표기다.

```text
A  D  B  C
E  A  F  D
B  E  C  F
```

카드가 가려진 뒤 첫째 줄 첫 번째 카드를 열면 A가 나온다. 이어서 둘째 줄 두 번째 카드를 열면 또 A가 나오므로 한 쌍을 완성한다.

다음 선택에서 B와 C처럼 서로 다른 카드를 열었다면 두 장은 다시 가려진다. 하지만 방금 확인한 위치는 다음 선택의 단서가 된다. 다른 위치에서 B를 발견했을 때 앞서 본 B의 위치를 기억하고 열면 짝을 맞출 수 있다.

이렇게 6쌍을 모두 찾았을 때 실제 플레이 시간이 18초였다면 1,000포인트, 9초였다면 보너스를 포함한 1,200포인트를 받는다. 30초가 끝났을 때 5쌍만 맞췄다면 성공 조건을 채우지 못해 0포인트다.

### 플레이어가 하는 판단

중심 행동은 **이미지와 위치를 기억하고, 새로 확인한 정보를 다음 선택에 활용하는 것**이다. 처음 공개된 배치를 기억하는 능력뿐 아니라, 틀린 선택으로 얻은 정보를 쌓아 짝을 찾아가는 과정도 게임의 내용이다. 스트리머의 이름을 몰라도 같은 프로필 이미지를 비교해 플레이할 수 있다.
