# 신규 미니게임 3종 기획서

**작성일:** 2026-09-17  
**기획 목적:** 기존 게임(회전 퍼즐, 확대 탐정, 시세 듀얼)을 대체하고, 기존 유지 게임(스트리머 퀴즈, 그림 짝맞추기)과 메커니즘이 겹치지 않는 신규 미니게임 구축

---

## 1. 신규 미니게임 공통 전제

1. **포인트 보상 체계**
   - **기본 성공:** 1,000포인트 지급
   - **보너스 조건 달성:** 200포인트 추가 지급 (총 1,200포인트)
2. **스트리머 원본 리소스 활용**
   - 별도의 이미지 가공(누끼/실루엣 추출 등) 없이 사이트에 등록된 기존 스트리머 카드/프로필 이미지를 원본 그대로 활용
3. **직관적이고 단순한 규칙**
   - 룰을 즉시 이해하고 모바일 및 PC 환경에서 간편하게 조작할 수 있는 규칙 채택

---

## 2. 게임 1: 팬 줄서기 (스와이프 / 좌우 분류)

### 2.1 게임 개요
- 중앙에 연속으로 등장하는 스트리머 카드가 좌측/우측 중 누구인지 빠르게 판단하여 넘기는 순발력 기반 아케이드 게임

### 2.2 화면 구성
- **상단 좌측:** 기준 스트리머 A (이름 및 대표 이미지)
- **상단 우측:** 기준 스트리머 B (이름 및 대표 이미지)
- **상단 중앙:** 제한시간(20초) 프로그레스 바 및 정답 수/콤보 표시
- **화면 중앙:** 차례대로 제시되는 스트리머 카드 덱 (A와 B의 이미지가 무작위 순서로 노출)
- **하단(모바일/PC 지원):** 좌측 넘기기 / 우측 넘기기 버튼 (또는 모바일 제스처 스와이프)

### 2.3 플레이 규칙
1. 카운트다운 후 **20초의 제한시간** 동안 게임이 진행된다.
2. 중앙에 나타난 카드가 스트리머 A의 이미지라면 **왼쪽**, B의 이미지라면 **오른쪽**으로 넘긴다.
3. 올바르게 넘길 때마다 즉시 다음 카드가 나타나며 카운트가 1 증가한다.
4. 오분류(실수) 시 카드 테두리에 약 0.5초간 붉은 표시와 안내가 나타나며 짧은 조작 딜레이(페널티)가 발생한다. 반복 점멸은 사용하지 않는다.

### 2.4 성공 조건 및 보상
| 판정 | 달성 조건 | 지급 포인트 |
|---|---|---:|
| **실패** | 20초 내 14장 이하 분류 | 0 pt |
| **성공** | 20초 내 **15장 이상** 올바르게 분류 | 1,000 pt |
| **성공 + 보너스** | 20초 내 **25장 이상** 올바르게 분류 (또는 오답 없이 20장 이상 분류) | 1,200 pt |

## 3. 게임 2: 게스트 캐치 (동체시력 / 타이밍 탭)

### 3.1 게임 개요
- 9개의 모니터 화면 사이에서 무작위로 깜빡이며 나타나는 여러 스트리머들 중, 지정된 '목표 스트리머'가 등장했을 때 정확히 터치해 낚아채는 동체시력 반응 게임

### 3.2 화면 구성
- **상단 안내:** "오늘의 게스트: [스트리머 C]" (목표 스트리머 카드 및 이름 고정 노출)
- **상단 인디케이터:** 남은 시간(25초), 현재 캐치 성공 횟수, 오클릭(실수) 횟수
- **중앙 그리드:** 3×3 (총 9개) 방송 화면/모니터 프레임

### 3.3 플레이 규칙
1. **25초의 제한시간** 동안 3×3 그리드 화면에서 무작위 스트리머들의 카드가 0.8~1.2초 주기로 켜졌다 사라진다.
2. 게임 전체에 걸쳐 목표 스트리머 C는 **총 10회** 등장한다.
3. 플레이어는 목표 스트리머 C가 켜졌을 때 해당 칸을 즉시 탭(클릭)해야 한다.
4. 다른 스트리머를 잘못 누르면 실수(오클릭)로 기록된다.

### 3.4 성공 조건 및 보상
| 판정 | 달성 조건 | 지급 포인트 |
|---|---|---:|
| **실패** | 목표 스트리머 6회 이하 캐치 또는 오클릭 3회 이상 | 0 pt |
| **성공** | 오클릭 2회 이하 & 목표 스트리머 **7회 이상 캐치** | 1,000 pt |
| **성공 + 보너스** | **오클릭 0회(무실수) & 목표 스트리머 10회 전체 퍼펙트 캐치** | 1,200 pt |

## 4. 게임 3: 순서 기억 (시퀀스 메모리 / 순서 맞추기)

### 4.1 게임 개요
- 상단 디스플레이 칸에 순서대로 지나가는 스트리머들의 이미지를 기억한 뒤, 하단 선택지 버튼을 제시된 순서 그대로 눌러 맞추는 단계별 기억력 게임

### 4.2 화면 구성
- **상단 프리뷰 영역:** 스트리머 이미지가 차례대로 노출되는 **[단일 이미지 디스플레이 칸]**
- **상단 인디케이터:** 현재 스테이지(총 5단계), 남은 라이프(기본 2회 제공)
- **하단 입력 영역 (선택지 카드 4장):**
  - **PC:** 가로 1열 배치 (1×4)
  - **모바일:** 화면 최적화 그리드 배치 (2×2)

### 4.3 플레이 규칙
1. 고정된 4명의 서로 다른 스트리머 카드(A, B, C, D)가 하단에 선택 버튼으로 배치된다.
2. 라운드가 시작되면 상단 디스플레이 칸에 스트리머 이미지가 약 0.7초 간격으로 순서대로 제시된다.
3. 제시가 끝나면 플레이어는 상단에 나왔던 순서와 동일하게 하단 카드를 탭하여 순서를 재현한다.
4. 난이도는 총 5단계로 진행되며, 기억해야 하는 카드 수가 순차적으로 늘어난다:
   - **1단계:** 4개 순서
   - **2단계:** 5개 순서
   - **3단계:** 6개 순서
   - **4단계:** 7개 순서
   - **5단계(최종):** 8개 순서
5. 입력 중 순서가 틀리면 라이프가 1회 차감되며, 해당 단계를 처음부터 다시 보여준다. 라이프를 2회 모두 소진하면 종료된다. 이미 4단계를 완료했다면 기본 성공 보상을 유지한다.
6. 전체 플레이는 최대 150초이며, 시간이 끝나면 완료한 단계에 따라 판정한다.

### 4.4 성공 조건 및 보상
| 판정 | 달성 조건 | 지급 포인트 |
|---|---|---:|
| **실패** | 3단계 이하에서 라이프 소진 | 0 pt |
| **성공** | **4단계(7개 순서)까지 클리어** | 1,000 pt |
| **성공 + 보너스** | 라이프 차감 없이 **5단계(8개 순서)까지 올클리어** | 1,200 pt |

## 5. 게임 교체 적용

- 일일 무작위 선택 및 기본 연습 목록: **스트리머 퀴즈, 그림 짝맞추기, 팬 줄서기, 게스트 캐치, 순서 기억**.
- 회전 퍼즐·확대 탐정·시세 듀얼은 연습 목록 하단의 작은 **이전 게임** 접이식 항목에서 제공한다. 새 보상 도전에는 선택되지 않는다.
- 연습은 티켓 차감과 포인트 지급이 없다. 보상 도전은 기존 티켓 정책과 0 / 1,000 / 1,200포인트 정량 보상을 따른다.
- 새 게임은 이미지를 미리 불러온 뒤 시작 버튼과 3초 카운트다운을 거친다. 플레이 시간과 판정은 서버에서 관리한다.
